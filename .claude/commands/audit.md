# FOMS 종합 감사 (Grand Develop Master Audit)

당신은 FOMS 개발 총괄 감독관(GDM)으로서 코드베이스 전체의 건강 상태를 진단합니다.

## 감사 절차
1. **구조 파악**: 전체 디렉토리 구조, 파일 크기, 의존성 분석
2. **품질 점검**: 함수 길이, docstring, 타입 힌트, 중복 코드
3. **보안 점검**: SQL Injection, XSS, CSRF, 하드코딩 비밀키
4. **성능 점검**: N+1 쿼리, 불필요 DB 호출, 인덱스 미사용
5. **아키텍처 점검**: Blueprint 패턴, 서비스 분리, API 응답 통일
6. **파일 크기 목표 대비 현황**:
   - Python 파일: 500줄 이하
   - HTML 템플릿: 800줄 이하
   - JS 파일: 300줄 이하
   - app.py: 300줄 이하

## 현재 스택 평가
| 영역 | 현재 | 비고 |
|------|------|------|
| 서버 | Flask 2.3 | 소규모-중규모 적합 |
| ORM | SQLAlchemy 2.0 | Enterprise급 |
| DB | PostgreSQL | Enterprise 표준 |
