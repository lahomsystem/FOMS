# 자동 상태 업데이트

> 이 워크플로우는 **git commit 직전**에 자동 실행됩니다.
> Cursor에서는 Hook(session_stop)이 자동 실행하고,
> Antigravity에서는 이 워크플로우를 참조합니다.

## 트리거
- git commit 실행 직전
- 작업 완료 보고 시

## 단계

// turbo-all

1. `docs/AI_STATUS.md` 파일을 읽는다.

2. 헤더의 "자동 업데이트" 날짜를 오늘로 변경하고, "마지막 작업"을 방금 완료한 작업 요약(1줄)으로 교체한다.

3. "최근 완료" 섹션에 방금 완료한 작업을 맨 위에 추가한다.
   - 형식: `- [{오늘날짜}] {작업 요약}`
   - 6개 이상이면 가장 오래된(맨 아래) 항목을 삭제한다.

4. "진행 중" 섹션을 업데이트한다.
   - 완료된 작업은 제거한다.
   - 아직 진행 중인 작업이 있으면 남긴다.
   - 없으면 `(없음)`으로 표시한다.

5. "알려진 이슈"에 이번 작업 중 발견된 이슈가 있으면 추가하고, 해결된 이슈는 제거한다.

6. "핵심 모듈" 테이블에 이번에 수정한 주요 파일이 없으면 추가한다.
   - docs/, .cursor/, static/css/ 등 메타 파일은 제외한다.

7. `docs/AI_CHANGELOG.md`에 새 행을 추가한다.
   - 형식: `| {날짜} | {작업 요약} | {수정 파일 3개+외N개} | {커밋 해시 앞7자} |`
   - 21개 이상이면 가장 오래된(맨 아래) 행을 삭제한다.

8. `AI_STATUS.md` 전체가 50줄을 초과하면 "최근 완료"에서 오래된 항목부터 삭제한다.

9. 변경된 `AI_STATUS.md`와 `AI_CHANGELOG.md`를 git add에 포함한다.

## 예시

**Before (AI_STATUS.md 헤더):**
```
> 자동 업데이트: 2026-02-27 | 마지막 작업: 지도 auto-poll 수정
```

**After:**
```
> 자동 업데이트: 2026-02-28 | 마지막 작업: 도면 업로드 UUID 충돌 방지
```
