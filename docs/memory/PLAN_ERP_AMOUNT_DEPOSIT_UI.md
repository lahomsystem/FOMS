## 요구사항 정리 (이해한 내용)

### 0. 예약금 입력란 – 1000단위 쉼표 표시

| 항목 | 내용 |
|------|------|
| 대상 | `#erp-deposit-amount` (예약금 입력 input) |
| 요구 | 입력/표시 시 **1000단위 쉼표(,)** 적용 (예: 1,000,000) |
| 유지 | 숫자만 저장·계산에 사용하고, 화면에는 포맷된 문자열 표시 |

---

### 1. 예약금·잔금 입력/표시 박스 – 출고가 뱃지 스타일 통일

| 항목 | 내용 |
|------|------|
| 기준 스타일 | 출고가 뱃지: `<div class="badge bg-primary flex-shrink-0" id="erp-items-total" style="font-size: 1rem;">0원</div>` |
| 예약금 | **동일한 뱃지 스타일**로 보이게 하되, **입력 기능은 유지** (편집 가능, 값 저장) |
| 잔금 | 동일 뱃지 스타일, **읽기 전용** (자동 계산값 표시) |

→ 출고가 / 예약금 / 잔금이 시각적으로 같은 뱃지 라인으로 보이도록 통일.

---

### 2. 예약금만 입력된 경우 (실측 전, 최종 견적 전)

| 항목 | 내용 |
|------|------|
| 조건 | 예약금 > 0 **그리고** 총 금액(항목 합계) = 0 또는 미입력 |
| 표시 | **‘예약금’ 항목** + **예약금액** 한 줄 표시 |
| UI 형태 | `input.form-control.form-control-sm` + `value="예약금액"` + `readonly` + `title="클릭하면 값이 복사됩니다."` |
| 의미 | 아직 실측/견적이 없어 출고가·잔금은 없고, “예약금만 받은 상태”만 보여주는 영역 |

---

### 3. 출고가·예약금·잔금 모두 표기 (실측 후, 최종 금액)

| 항목 | 내용 |
|------|------|
| 조건 | 총 금액(항목 합계) > 0 (실측 끝난 뒤 최종 금액이 있는 상태) |
| 표시 | **출고가** / **예약금(선금)** / **잔금** 세 줄 모두 표기 |
| UI 형태 | 각 줄마다 `input.form-control.form-control-sm` + `value="금액"` + `readonly` + `title="클릭하면 값이 복사됩니다."` |
| 계산 | 출고가 = 총 금액, 예약금 = 사용자 입력값(없으면 0), 잔금 = 출고가 − 예약금 |

---

## 상태별 표시 요약

| 상태 | 총 금액 | 예약금 | 표시 내용 |
|------|--------|--------|-----------|
| 실측 전 (예약금만) | 0 | > 0 | **예약금** 항목 + 예약금액 (readonly, 클릭 시 복사) |
| 실측 후 (최종 금액) | > 0 | 임의 | **출고가** / **예약금(선금)** / **잔금** 세 줄 (모두 readonly, 클릭 시 복사) |

- 항상 **예약금 입력란**은 유지(입력 가능, 뱃지 스타일).
- 총 금액이 0일 때는 “예약금만 표시” 영역만 보이고, 총 금액이 있을 때는 “출고가/예약금/잔금” 영역을 보여주는 식으로 **조건부 표시** 적용.

---

## 구현 범위 (계획)

1. **HTML**  
   - 예약금 input: 뱃지 스타일 적용, `type="text"` 등 쉼표 표시 가능하도록 조정.  
   - 잔금: 뱃지 스타일 + readonly.  
   - “예약금만 표시” 영역 1줄 (readonly input, 클릭 시 복사).  
   - “출고가/예약금/잔금” 영역 3줄 (readonly input, 클릭 시 복사).

2. **JavaScript**  
   - 예약금: 입력 시 1000단위 쉼표 포맷, 저장/계산 시 숫자만 사용.  
   - 잔금 자동 계산 및 표시.  
   - 조건에 따라 “예약금만 표시” / “출고가·예약금·잔금” 영역 표시·숨김.  
   - readonly 필드 클릭 시 값 복사 (title 문구와 동일 동작).

3. **저장/로드**  
   - 기존처럼 예약금 숫자만 `structured_data.payment.deposit` 등에 저장·로드.
