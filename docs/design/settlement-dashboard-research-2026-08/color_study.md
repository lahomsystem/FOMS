# 정산 대시보드 색상/디자인 연구 — 전략 요약

2026-08-31 · 대상: `docs/design/mockups/settlement-dashboard-v1-executive.html` · `-v2-operations.html` · `-v3-analytics.html` · `-v3-analytics-light.html`
시각 비교 보드: `docs/design/mockups/settlement-color-study.html`

## 0. 문제 정의

사용자 피드백: "그래프 색상이 너무 획일화 돼 있다 — 금액구간별로 달리 할지 / 단조로운 디자인을 어떻게 할지."
현황: 4개 목업 모두 카테고리 slot-1 파랑(`#2a78d6`)이 사실상 유일한 데이터 색. 예외는 채널 slot-2 주황, aging의 파랑 ordinal 램프뿐. 차트 문법은 규칙에 맞지만 **모든 지표가 같은 파랑을 입어서 "색 = 의미" 정보가 0**이고, 카드 표면도 전부 동일한 흰 카드라 화면 전체가 평평하다.

판정 기준(dataviz 스킬 — 위반 제안 금지): 무지개 금지 · 범주색 순환 금지 · 시퀀셜=단일 색상 명암 · 상태색은 상태에만 · **색은 값/순위가 아니라 엔티티를 따라간다** · 팔레트는 `validate_palette.js`로만 판정(눈대중 금지).

## 전략 A — 금액구간별 시퀀셜 램프 (사용자 제안)

**내용**: 금액을 구간(버킷)으로 나눠 한 색상(파랑)의 명암 램프를 입힌다. 큰 금액 = 진한 색.

**어디서 합법인가** — *구간 자체가 의미 단위일 때*:
- **미수금 aging** (7일 이하 → 91일 이상): 경과일 버킷이 곧 분석 단위(ordinal). 이미 V1·V2가 blue 250→650 램프로 적용 중이며 `--ordinal` 검증 PASS. 사용자 제안이 이미 절반은 구현돼 있는 셈.
- (미래 후보) **달력/요일×주차 히트맵**: 셀 크기가 값을 못 나타내는 형태에서는 시퀀셜 램프가 값 인코딩의 정석.
- **진행 단계별 물린 금액**: 단계(접수→CS)는 순서 있는 ordinal 카테고리이므로 *단계 순서*를 램프에 태우는 것은 합법. 단, *금액*을 램프에 태우면 아래의 불법 케이스가 된다.

**어디서 안티패턴인가** — *막대 높이가 이미 금액을 인코딩할 때*:
- **출고가 매출 추이(일별 막대)**: anti-patterns.md "❌ A value-ramp on nominal categories" 그대로 — 막대 길이가 이미 보여주는 값을 색으로 중복 인코딩하고, 유일하게 남은 자유 채널(색=정체성)을 낭비한다. 날짜별로 색이 튀어 **가짜 범주**처럼 읽히고, 구간 경계(699만 vs 701만)에서 거의 같은 값이 다른 색을 입는 계단 왜곡이 생긴다. 비교 보드 A열에서 실물로 확인 가능.
- 채널·부서 같은 명목 카테고리 막대도 동일하게 금지.

- 장점: 사용자 직관과 일치 · aging에는 이미 합법 적용 · 추가 색상 도입 없음.
- 단점: 합법 표면이 aging 한 곳(+미래 히트맵)뿐이라 "단조로움 해소" 확장성이 없음 · 매출 추이에 쓰면 규칙 위반 · 같은 파랑 명암이라 체감 변화도 작음.
- 규칙 정합: 조건부 — ordinal/시퀀셜 문맥만 합법, 값-램프는 불법.
- 카드 매핑: 유지(aging) · 신규 확대 비추천.
- **추천 여부: 부분 채택** (현행 aging 램프 유지, 그 이상 확대 금지).

## 전략 B — 지표 계열별 색 배정 (색이 엔티티를 따라가는 정석)

**내용**: 대시보드 전체에 **"지표 가족 → 색" 사전**을 하나 정해서 4개 목업이 공유한다.

| 지표 가족 | 색 | 근거 |
|---|---|---|
| 매출 (추이·평균 출고가·물린 금액) | 파랑 slot-1 `#2a78d6` | 현행 유지 — 주 지표 |
| 기간 비교(전월) | 같은 파랑의 다크 스텝 `#1c5cab` | before→after = 1 hue 2 shades (`--ordinal` PASS) |
| 수금 (당월 수금·현금흐름 예측) | 아쿠아 slot-3 `#1baf7a` | 슬롯 1·2·3은 all-pairs PASS 트리오 |
| 미수/연체 (aging·미수 KPI) | 주황 램프 `#f19979→#752600` (slot-2 계열) | "두 번째 시퀀셜은 다음 슬롯 hue" — palette.md 명문 규칙 |
| 위험 강조 (91일+, 연체 경보) | status critical `#d03b3b` + 아이콘·라벨 | 상태를 *의미*할 때만 status 토큰 |
| 채널 (일반/네이버) | 범주 slot-1/slot-2 | 현행 유지 |
| 볼륨/보조 (건수 등) | 뉴트럴 `#6b7280` 계열 | 색 사전을 아끼는 절제 |

- 장점: **색이 값이 아니라 지표(엔티티)를 따라감** — 규칙의 정석 · 화면 어디서든 "파랑=매출, 주황=미수, 아쿠아=수금"이 학습됨(색이 장식이 아니라 정보가 됨) · 4개 목업 전 카드에 일반화 가능 · 단조로움을 실질 해소.
- 단점: 색 사전 유지 규율 필요(새 카드마다 가족 판정) · 파랑+주황 두 시퀀셜 공존은 허용 규칙이지만 한 화면 2개까지로 절제 필요.
- 규칙 정합: 완전 — 사용 팔레트 전부 검증 PASS (하단 검증 기록). `#1baf7a`는 2.82:1 relief 밴드 → KPI 값 병기·표 뷰로 충족(WARN, exit 0).
- 카드 매핑(V1 기준): 메인 추이 = 파랑(당월 `#2a78d6` 막대 + 전월 `#1c5cab` 라인) · aging = 주황 램프 + 91일+ 각주에 critical · 현금흐름 예측 = 아쿠아 · 채널 = slot-1/2 · KPI 스파크라인 = 가족색 · 정산 처리 미터 = 파랑 유지.
- **추천 여부: 최우선 채택.**

## 전략 C — 강조(emphasis) 전략 (모노톤의 세련된 해법)

**내용**: 대부분 시리즈를 뉴트럴 그레이 `#8a94a3`(흰 서피스 3.07:1 ≥ 3:1)로 눕히고, **이야기가 있는 시리즈·이상치만** 색을 준다. choosing-a-form.md: "Emphasis = the most underused form."

- 적용 예(보드 C열): 매출 추이 — 31개 막대 전부 그레이, 최고 매출일(8/31 `1,113만`)만 파랑 + 직접 라벨, 전월 라인은 다크 그레이 `#6b7280` · aging — 4개 버킷 그레이, **91일 이상만 critical 빨강** + 아이콘·라벨(현행 각주를 색으로 승격).
- 장점: 시선이 정확히 한 점에 꽂힘 — 경영진 뷰(V1)와 궁합 최상 · 절제된 고급감 · 상태색 원칙(빨강=진짜 위험)과 자연 결합.
- 단점: **전 카드에 쓰면 오히려 더 모노톤**(회색 대시보드 — 사용자 불만의 역방향 악화) · "무엇을 강조할지" 선정 로직이 카드마다 필요 · 색=의미 사전이 생기지 않음.
- 규칙 정합: 완전 — 강조 그레이는 채도가 낮아 카테고리 슬롯이 아니며(의도된 de-emphasis 채널), 강조색·critical은 대비 PASS.
- 카드 매핑: aging 91일+ 강조(즉시 채택 가치) · 월별 보기의 당월 강조(V2가 이미 함) · 목표 미터.
- **추천 여부: 보조 채택** — B 위에 국소(카드 1~2곳) 강조로만.

## 전략 D — 표면/배경 층위 변화 (차트 밖 단조로움 해소)

**내용**: 데이터 잉크는 그대로 두고 **카드·섹션·헤더의 표면 층위**로 리듬을 만든다: KPI 카드 가족 틴트(5~8% 워시) + 상단 액센트 바 3px + 가족색 스파크라인, 섹션 밴드(그라데이션 워시), 헤더 스트립.

- 장점: 차트 규칙과 완전 직교(마크가 아니라 서피스 — dataviz 검증 대상 아님, 텍스트 대비만 유지하면 됨) · 리스크 낮고 체감 큼 · "화면이 평평하다"는 불만의 직접 해답.
- 단점: 틴트가 8%를 넘으면 촌스러워짐 · 상태색 오독 주의(빨강 계열 틴트 카드는 금지 — 미수 카드의 주황 틴트는 실제 위험 지표라 허용) · 색 틴트는 B의 가족 사전과 **반드시 같은 사전**을 써야 함(따로 놀면 혼란).
- 규칙 정합: 완전(비-데이터 표면). KPI delta의 good/bad 상태색은 화살표+텍스트 이중 신호 유지.
- 카드 매핑: KPI 5장 가족 틴트+액센트 바(보드 하단 데모) · row-B 섹션 밴드 · 헤더 스트립 그라데이션.
- **추천 여부: B와 병행 채택.**

## CEO 추천: **전략 B (지표 계열별 색 배정)** — D 병행, C 국소 보조, A는 현행 aging 유지로 종결

1. B만이 "색이 엔티티를 따라간다"는 규칙의 정석이면서 4개 목업 전 카드에 일반화된다 — 사용 팔레트 전부 `validate_palette.js` PASS(exit 0)로 이미 검증 완료.
2. "파랑=매출 · 주황=미수 · 아쿠아=수금" 색 사전이 생겨 단조로움 해소가 장식이 아니라 **정보**가 된다 — 사용자가 화면을 오갈수록 학습이 누적된다.
3. A는 합법 표면이 aging 한 곳뿐이라 확장성이 없고(매출 추이 적용은 안티패턴), C는 전면 적용 시 더 모노톤 — "B 기본 + D 표면 리듬 + C 국소 강조"가 재사용 가능한 최소 규칙 세트다.
