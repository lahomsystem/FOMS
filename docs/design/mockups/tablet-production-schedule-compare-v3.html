도면 내려온 때 · 누가있음사장님 답대로 = 생산 단계로 넘어간 때. 단계를 옮길 때 남는 기록(고객 컨펌 끝 · 단계 변경 · 강제 변경 · 바로 제작 시작)의 시각 · 누른 사람. 생산 화면의 '바뀐 것' 계산이 이미 이 시각("마지막 생산 진입")을 구해요.
도면 마감셈 — 있음회사 달력(주말 · 공휴일 뺌)의 "일하는 날 2일 앞". 11/24 → 11/20 (금), 11/25 → 11/23 (월), 11/28 (토) · 11/30 (월) → 둘 다 11/26 (목). 코드로 다시 돌려 확인했어요.
안 온 까닭 · 누구 일있는 값으로 셈주문 단계 + 도면 상태 · 도면 담당(여러 명 가능) · 영업 담당. 칩의 한 마디: 도면 = 그리는 중(도면 담당 일) · 담당 없음 = 도면 담당이 비었음 · 확인 = 도면을 보냈고 영업 수령 확정 기다림 · 수정 = 영업이 수정 요청 · 컨펌 = 고객 컨펌 기다림(영업 일).
