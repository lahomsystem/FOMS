정산 대시보드 색상 연구 전략 비교 보드 피드백 "그래프 색상이 너무 획일화" 대응 — V1 실데이터(가정치) 동일 적용 기준 2026-08-31

같은 두 차트(출고가 매출 추이 = 8월 막대 + 7월 라인, 미수금 aging)에 색 전략 A·B·C를 각각 적용해 나란히 비교합니다. 하단은 차트 밖 단조로움을 해소하는 전략 D(표면 층위) 데모. 모든 팔레트는 dataviz validate_palette.js로 검증했습니다(기록: 소스 하단 주석 · color_study.md).

전략 A — 금액구간별 램프 부분 채택
금액을 구간으로 나눠 같은 파랑의 명암으로 칠한다(사용자 제안) — 큰 금액일수록 진하게.
출고가 매출 추이 안티패턴 시연
막대 높이가 이미 금액인데 색이 또 금액을 말한다 — 이중 인코딩. 699만 vs 701만이 경계에서 다른 색을 입어 날짜들이 가짜 범주처럼 읽힌다.
미수금 aging 합법 — 현행 유지
91일 이상 1건 · 150만 — 우선 회수 대상. 경과일 버킷 자체가 의미 단위(ordinal)라 램프가 정당 — V1이 이미 이렇게 한다.
장점 직관적("클수록 진하게") · aging엔 이미 합법 적용 · 새 색상 불필요
단점 합법 표면이 aging뿐이라 확장성 없음 · 추이 막대에 쓰면 규칙 위반 · 같은 파랑 명암이라 체감 변화도 작음
판정 aging 현행 유지로 종결, 그 외 확대 금지.
전략 B — 지표 계열별 색 CEO 추천
색이 값이 아니라 지표 가족(엔티티)을 따라간다: 매출=파랑 · 미수=주황 램프 · 수금=아쿠아 · 위험=빨강 status · 채널=범주 슬롯.
출고가 매출 추이 정석 — 1 hue 2 shades
두 시리즈 모두 매출 가족 = 파랑. 색은 엔티티를, 명암이 기간(당월/전월)을 맡는다 — before→after 표준형. 검증 #2a78d6,#1c5cab --ordinal PASS.
미수금 aging 정석 — 두 번째 시퀀셜=slot-2 hue
91일 이상 1건 · 150만 — 우선 회수 대상. 미수는 주황 가족 — 파랑(매출)과 한눈에 구분되고, 화면 어디서든 "주황=미수"가 학습된다.
장점 색=의미 사전("파랑=매출·주황=미수·아쿠아=수금") · 4개 목업 전 카드에 일반화 · 팔레트 전부 검증 PASS
단점 색 사전 유지 규율 필요(새 카드마다 가족 판정) · 한 화면 시퀀셜 램프는 2개까지로 절제
판정 기본 전략으로 채택 — D와 병행.
전략 C — 강조(emphasis) 보조 채택
대부분을 뉴트럴 그레이로 눕히고, 이야기가 있는 지점만 색을 준다 — 모노톤의 세련된 해법.
출고가 매출 추이 합법 — 강조 1점
31개 막대를 그레이로 눕히고 월 최고 매출일(8/31)만 파랑 + 직접 라벨. 시선이 정확히 한 점에 꽂힌다 — 경영진 뷰와 궁합 최상.
미수금 aging 합법 — status 강조
91일 이상 1건 · 150만 — 우선 회수 대상. 위험을 의미하는 막대만 critical 빨강 + 아이콘·라벨 — 상태색 원칙과 정확히 일치.
장점 시선 집중·절제된 고급감 · "이번 달 이야기"가 명확 · 상태색 원칙과 자연 결합
단점 전 카드에 쓰면 더 모노톤(회색 대시보드 — 불만의 역방향) · 강조 대상 선정 로직 필요 · 색=의미 사전이 안 생김
판정 B 위에 국소(카드 1~2곳) 강조로만.

전략 D — 표면/배경 층위 변화 B와 병행

데이터 잉크(마크)는 그대로 두고 카드·섹션 표면으로 리듬을 만든다 — 차트 규칙과 직교라 위반 리스크 0. 아래는 V1 상단 KPI 5장 미니 재현: 현재 vs D 적용(가족 틴트 5~8% 워시 + 상단 액센트 바 + 가족색 스파크라인 + 섹션 밴드). 틴트 가족은 전략 B의 색 사전을 그대로 재사용한다(따로 놀면 혼란).

현재 — V1 그대로 (전 카드 동일 흰 표면 · 스파크라인 전부 파랑)
전략 D 적용 — 매출·평균출고가=파랑 · 미수금=주황 · 수금=아쿠아 · 건수=뉴트럴
장점 리스크 최소(마크가 아니라 서피스 — dataviz 검증 대상 밖, 텍스트 대비만 유지) · "화면이 평평하다"는 불만의 직접 해답
단점 틴트가 8%를 넘으면 촌스러움 · 빨강 계열 틴트 카드는 금지(상태색 오독) — 미수 카드 주황 틴트는 실제 위험 지표라 허용
판정 B와 같은 색 사전으로 병행 채택. 델타(▲▼)의 good/bad 상태색은 그대로 둔다.
CEO 추천 — 전략 B(지표 계열별 색 배정) 기본 + D(표면 층위) 병행. ① B만이 "색이 엔티티를 따라간다"는 규칙의 정석이면서 4개 목업 전 카드에 일반화되고, 사용 팔레트 전부 validate_palette.js PASS. ② "파랑=매출·주황=미수·아쿠아=수금" 색 사전이 생겨 단조로움 해소가 장식이 아니라 정보가 된다. ③ A는 합법 표면이 aging 한 곳뿐(추이 적용은 안티패턴), C는 전면 적용 시 더 모노톤 — B 기본 + D 표면 리듬 + C 국소 강조가 재사용 가능한 최소 규칙 세트.
