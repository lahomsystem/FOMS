ERP 주문 — 할인 항목별 추가

할인 칸 하나 대신 "할인 이름 + 금액" 줄을 여러 개 둔다. 합계는 자동으로 더하고, 잔금 = 출고가 − 예약금 − 할인 합계로 계산한다. 아래 두 화면은 같은 값을 공유하니 한쪽에서 고치면 다른 쪽도 바뀐다.

정해야 할 것 · 동작 규칙

저장 형태 — structured_data.payment 에 discounts 배열을 두고, 옛 discount 숫자는 합계로 계속 채운다(정산·견적·옛 화면 호환). 
"payment": {
  "discounts": [{"label": "오픈 특가", "amount": 100000},
                {"label": "지인 할인", "amount": 50000}],
  "discount": 150000
}
옛 주문 — discount 숫자만 있으면 "할인" 이름 한 줄로 보여 준다.
PUSH·변환 텍스트 — 줄마다 "할인(오픈 특가) : 100,000원" 처럼 나가고, 합계 줄을 붙일지 정해야 한다.
모바일 — 줄은 카드로 보이고, 누르면 고치기, × 로 지우기. 입력칸은 16px 이상이라 아이폰이 확대하지 않는다.
