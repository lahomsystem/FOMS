Frame 1 — 메인: 견적 워크시트 + 라이브 견적 패널

상담원의 시선 흐름 = 왼쪽에서 입력, 오른쪽에서 읽기. 좌측 워크시트에 입력 전부(구성·옵션·비고·조정), 우측 패널에 계산 결과 전부(현재 견적 브레이크다운 → 진행 견적 스택 → 전체 합계)를 상주. D/H 열 제거, 단가 셀은 금액만(×구간 메타 삭제). 2행 = MINE 행(구 직접): 메인 행은 제품명이 전폭 사용, 방식 드롭다운(30cm▾)+단가 입력은 작은 서브행으로 분리 — 제품명 잘림 없음, 입력한 제품명이 견적서에 그대로 표기. 1행 하단 = 행별 직접입력(구 추가금): 이름+금액 서브행, 견적서엔 입력한 이름만 표기("추가금" 접미사 삭제). 비고는 정식 섹션으로 승격, 조정 스트립엔 할인·배송만. [견적 계산] 버튼 삭제(PC·모바일·태블릿 공통) — 계산은 모든 입력 경로에서 이미 자동, 액션바는 [진행 견적에 추가] 하나로 단순화.

설계 근거 요약

persona: 상담팀 — 통화/대면 중 입력 90%가 제품 선택+W 타이핑. 시선 분산 상태에서도 총액·진행 견적이 항상 보여야 함.
중요도 위계: W 입력(18px 볼드·128px)과 제품/제품명(1fr)이 가장 크고, 할인·배송(104px)은 하단 스트립으로 압축. 비고는 견적서 표기 항목이라 정식 섹션. D/H 열 제거(W 기준 가격), 단가 셀은 금액만.
PC 기능 100% 이식 + 엔진 확장 5점(PC·모바일·태블릿 공통): ① MINE(구 직접) 행 제품명 입력·견적서 표기 ② 30cm/1m 컴팩트 드롭다운(태블릿·모바일) ③ "직접"→"MINE", "추가금 추가"→"직접입력" 리네임 ④ 행별 직접입력 표기에서 "추가금" 접미사 삭제(입력한 이름만) ⑤ [견적 계산] 버튼 삭제(계산은 전 입력 경로 자동 — 죽은 버튼 정리).
구현 아키텍처: 계산·저장 엔진 코어는 무접촉, 위 5점만 최소 확장. 태블릿 표면 = 신규 DOM + 은닉 엔진 위젯 양방향 미러(검증된 T16/T18 패턴). 총견적 실시간 = 자동 계산 결과 미러(표시 전용).
