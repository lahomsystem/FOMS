생산 작업자 화면 시안 넷

지금 만들어 둔 태블릿 화면(왼쪽 레일 + 칸반 + 옆에서 나오는 시트)은 관리자가 PC 에서 보던 판을 태블릿에 옮긴 것이에요. 이 네 장은 반대로 작업대 앞에 선 사람이 하루에 실제로 하는 일에서 출발했어요. "전체 주문이 어디까지 왔나 → 도면 보며 만들고 체크 → 내 기계에 온 줄 처리 → 일정·바뀐 것 확인" 순서예요. 데이터는 전부 가짜예요.

  • 기종 갤럭시 탭 가로 1280×800
  • 장갑 단추 56px 이상, 글자 16px 이상, 끌기 없음

어떻게 고를까

사용자 결정(11-09)으로 첫 화면은 안 1 전체 주문이에요. 주문을 누르면 안 2가 전체 화면으로 열려요. 안 3(내 공정 줄)과 안 4(일정과 바뀐 것)는 첫 화면 위 세 칸 옆에 탭으로 붙이거나 레일에서 여는 후보예요. 지금 승인된 설계서(레일 + 시트 고치기)는 "지금 있는 것을 생산팀이 쓸 수 있게"이고, 이 넷은 "생산팀만의 첫 화면을 따로 두기"예요. 둘은 같이 갈 수 있어요.

이번에 정한 것(11-09)

  • 첫 화면은 전체 주문 — 오늘 할 일만이 아니라 도면 기다리는 것부터 시공 중까지 한 줄. 안 1 을 그렇게 고쳤어요.
