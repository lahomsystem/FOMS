# AI 도면팀원 — 고칠 것 (위가 먼저)

1. **운영 반영 뒤 첫 측정** — 학습 요약을 받아 METRICS 첫 줄, 기억 줄이 쌓이는 속도 · 사람 이름표 비율 확인.
2. **기억 문턱 맞추기** — 사람 이름표끼리 닮음 분포 · 같이 고치기 되돌림으로 `min_sim`(0.95) · `min_sim_door`(0.985) 검토.
3. **검수 메모 끈 비율** — 2주 모아 50% 넘는 메모는 고치거나 뺀다. 특히 '치수 글자 8px' · '자재표 다름'(계산식 정확도 77~85%).
4. **분류기 다시 가르치기** — 고친 기록 100건이 모이면 학습 요약으로(그림 없이) 새 판을 만들어 판정.
5. **기억 끄기 · 측정 도구** — 기억을 줄 단위로 끄는 관리 길, 기억이 맞힌 비율을 재는 도구(설계서 2026-10-26 남은 것).
6. **자재표 계산식** — 계산 칸과 최종 자재표 차이로 SR · 문 폭 · 옷봉 · 마이다 식을 다듬는다(넣기 단추는 도면팀 확인 뒤).
7. **초안 맡기(A4)** — 도면팀이 A1 ~ A3 를 써 본 뒤. 그림만 올리면 분류 · 배치 · 머리칸 · 자재표 계산까지 정리한 초안.
8. **루틴이 스테이징까지 혼자 올리는 길** — 지금은 저장소 가드가 deploy 푸시를 '사람 확인'으로 막아 루틴은 `drawing-agent/<날짜>` 브랜치까지만 올린다. 2주 보고 뒤 사용자 결정으로 가드 예외(루틴 전용 · fast-forward 만)를 설계한다.
