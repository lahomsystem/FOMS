## Step 3. 수동 핵심 시나리오 (약 15~30분)

### 3-1. 도면 전달

1. 주문 상세 → 도면 탭 이동
2. 도면 파일 업로드
3. **"도면 전달"** 버튼 클릭
4. **확인**: 상태가 "전달됨" 등으로 바뀌고, 화면에 반영됨 ✅

---

### 3-2. 도면 전달 취소

1. 도면 전달된 주문 선택
2. **"도면 전달 취소"** 버튼 클릭
3. **확인**: 상태가 취소되고, 화면에 반영됨 ✅

---

### 3-3. 도면 수정 요청

1. 도면 전달(또는 확정 대기) 상태인 주문 선택
2. **"수정 요청"** 버튼 클릭
3. 메모 입력 후 확인
4. **확인**: 상태가 "수정 요청됨" 등으로 바뀜 ✅

---

### 3-4. 완료처리 실패 시 rollback

1. 주문을 **완료 처리 불가 조건**으로 설정 (예: 이전 단계 미완료)
2. 완료 버튼 클릭 시도
3. **확인**: 에러 메시지 나오고, DB는 롤백되어 이전 상태 유지 ✅

---

### 3-5. structured save 후 이벤트/자동화

1. 주문 상세 → structured 데이터 수정 (단계 전환 등)
2. 저장
3. **확인**: 저장 성공, 이벤트/알림/자동화가 기대대로 동작 ✅

---

### 3-6. 시공 첨부 재업로드

1. 시공(Construction) 단계 주문 선택
2. 첨부 파일 삭제 후 새 파일 업로드
3. **확인**: 업로드 성공, 목록에 새 파일 표시됨 ✅

---

### 3-7. 실측 mine=1 필터 (선택)

1. 실측 대시보드에서 "내 담당" 또는 mine 필터 적용
2. **확인**: 내 담당 주문만 보임 ✅

---

### 3-8. ERP/실측/출고/AS 검색 (선택)

1. 각 대시보드에서 검색창에 고객명·전화번호 등 입력
2. **확인**: 검색 결과가 정상적으로 필터링됨 ✅

## 문제 발생 시

- **화면 안 뜸**: F12 Console 에러 확인 → 서버 로그 확인
- **저장 안 됨**: Network 탭에서 API 응답 확인 (200/400/500)
- **DB 롤백 의심**: 해당 주문 상태를 DB에서 직접 확인
