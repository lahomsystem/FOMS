# 계획 — 네이버 발송처리 자동 실행(평일 16:50) · NAVER-AUTODISPATCH-01

- 진행 원장: `docs/plans/2026-09-02-naver-auto-dispatch-ledger.md`
- 선행: `docs/plans/2026-08-31-naver-bulk-dispatch-result-ui-ledger.md`(수동 일괄 발송처리)

## 문제

오늘 실측한 네이버 건의 발송처리를 사람이 매일 화면에서 눌러 왔다. 누르는 것을 잊으면
그날 건이 통째로 밀리고, 늦은 발송은 네이버 지연 페널티로 이어진다.

## 사용자 결정 (2026-09-02)

1. **평일만 + 공휴일 제외** (토·일·한국 공휴일에는 안 보낸다).
2. 대상 판정은 **수동 버튼과 똑같이** — '실측 완료 표시 없음' 집도 보낸다(기준을 둘로
   가르면 사람이 어느 쪽을 믿을지 모른다).
3. **예행 없이 바로 실제 발송.** 수동 버튼은 그대로 두고, 이미 수동으로 보낸 날에는
   자동이 보낼 것이 없어 조용히 지나간다.

## 설계

### 실행 자리 = 워커 컨테이너의 백그라운드 루프 (기존 관례)

FOMS 에는 인앱 스케줄러가 없다. 알림 escalation·좌표 스윕·네이버 수집 5분 스윕이 전부
`start.sh` 의 워커 분기에서 `--loop` 러너로 돈다. 같은 자리에 하나 더 붙인다 — 새 인프라
의존성(rq-scheduler·외부 cron)을 만들지 않는다. 네이버 HTTP 가 WORKER 에서만 나가야 하는
IP 계약과도 맞는다.

### 안전 규율 다섯

1. **대상은 서버가 다시 계산한다** — 수동 라우트와 같은 `select_sendable`. 막힌 집
   (취소·반품 걸림·발주확인 전·수집 이상)은 지금처럼 안 나간다.
2. **하루 1회** — `SystemSetting`(`naver_auto_dispatch_state`)에 마지막 실행 날짜를 남겨
   워커 재시작·replica 가 늘어도 두 번 나가지 않는다.
3. **영업일만** — `business_calendar.is_business_day`(주말+공휴일). 달력을 새로 만들지 않는다.
4. **기본 꺼짐** — `FOMS_NAVER_AUTO_DISPATCH_ENABLED=1` 로만 켠다. 기존 일괄 발송 킬스위치
   (`is_naver_bulk_dispatch_enabled`)도 함께 봐서, 그게 꺼져 있으면 자동도 돌지 않는다.
5. **말없이 나가지 않는다** — 보낸 집이 있으면 감사 원장 + 관리자 알림 1건(보낸 집·막힌 집).
   0집이면 조용히 지나간다(매일 뜨는 알림은 읽히지 않는다).

## Task

| task | 내용 | 완료 기준 |
|---|---|---|
| T1 | `run_auto_dispatch()` 서비스 — 게이트·영업일·하루1회·대상 재계산·감사·알림 | 신규 테스트: 주말/공휴일 skip · 하루 두 번 실행해도 1회 · 대상 0집이면 무발송·무알림 · 막힌 집 제외 · 게이트 off 면 호출 0 |
| T2 | 러너 `scripts/maintenance/run_naver_auto_dispatch.py` (`--once`/`--loop --at HH:MM`) | 창 밖 시각엔 실행 안 함 · 실패해도 루프 유지 · `--once` 로 수동 점검 가능 |
| T3 | `start.sh` 워커 분기 배선 + env 3종(기본 OFF) | 게이트 off 면 프로세스 추가 없음 · 계약 테스트 |
| T4 | 화면 한 줄 — "평일 16:50 자동 발송" 안내(자동이 켜져 있을 때만) | 두 띠 계약 · 꺼져 있으면 문구 없음 |
| T5 | 게이트·푸시·승격 | pre_push_smoke exit 0 · CI 전 워크플로 green · 운영 승격 PR |

## 위험과 대응

- **워커 재배포가 필요하다**(`start.sh` 변경). 워커 1대라 재배포 = 큐 전면 정지.
  → 승격 후 `tools/ops/check_worker_redeploy_safe.py` 로 판정하고, 큐가 빈 시각에 사용자
  승인 하에 재배포한다. 16:50 직전·직후는 피한다.
- **불가역 조작의 무인화** — 되돌릴 수 없다. 그래서 기본 꺼짐 + 결과 알림 + 감사 기록이
  한 세트다. 끄는 것이 롤백 경로다(env 하나).

## 안 하는 것

- 예행(dry-run) 모드로 며칠 관찰 — 사용자가 바로 실제 발송을 택했다.
- 수동 버튼 제거 — 그대로 둔다(자동이 안 도는 날·남은 집 재시도 경로).
- 발송 시각을 화면에서 바꾸는 설정 UI — env 로 둔다(바꿀 일이 드물다).
