  `$2a$…` 로 시작하는 secret 이 **29자 → 27자로 잘렸다**(셸이 `$2` 를 위치 매개변수로 확장).

  STAFF 응답에 이력 데이터 0.

## 전량 승격을 다시 할 일이 생기면

로드맵 §13~§16 에 **재현 가능한 절차와 실측값**이 전부 있다. 핵심만:

1. 승격 대상 SHA 를 **CI 전량 green 인 것으로 못박아라**(브랜치명으로 병합하면 타 세션
   push 시 게이트가 조용히 거짓말한다).
2. 유일한 판정 게이트는 **`git diff --stat <대상SHA>` 무출력**이다. 파일별 grep 20여 개를
   대체하고, 3-way 머지의 **비충돌 파일 keep-both 중복**까지 잡는다(실제로 그렇게 찾았다).
3. `production` 이 기여하는 신규 내용이 0 이면 올바른 병합 = deploy 트리다.
   확인법: `production` 에만 있는 파일 0개 · `requirements.txt` diff 무출력 ·
   `git cherry` 의 `+` 커밋을 **개별 대조**.
4. **데이터 전제를 코드 정합과 따로 봐라.** 이번에 막은 것이 그것이다 — 컬럼은 있는데
   전 행 NULL 이었고, 새 코드가 그 컬럼을 모집단 술어로 쓴다. CI 는 시드 DB 라
   **구조적으로 드러낼 수 없다.**

진행 상황은 나한테 매우 상세히 물어봐.
