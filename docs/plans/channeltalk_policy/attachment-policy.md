# Attachment Policy (CT-B-02)

## 1. 첨부 파일 전송 기준
ChannelTalk 전송 시, 첨부파일은 용량 제한과 네트워크 병목, 채널톡 과금을 고려하여 제어한다.

### 1.1. 제한 규정
- **수량 제한**: 1회 Push 당 **최대 10개**까지만 허용 (이후 파일은 생략됨).
- **크기 제한**: 1개 파일당 최대 용량은 채널톡 API 제한(통상 50MB)을 준수 (사전 R2 스토리지에서 용량 확인).
- **형식 제한**: 이미지(jpg, png, webp, gif), 동영상(mp4, mov). 그 외 문서/압축파일은 전송 제외.

### 1.2. Presigned URL 관리
- 모든 파일은 Cloudflare R2의 Presigned URL을 발급받아 ChannelTalk에 전달한다.
- **만료 시간(TTL)**: ChannelTalk API가 다운로드할 시간을 고려해 1시간(3600초)으로 설정.
- DB에 로깅할 때(`ChannelDeliveryLog.file_snapshot`)는 보안을 위해 Presigned URL을 그대로 저장하지 않고 `[MASKED]` 처리하거나 Object Key만 남긴다.

## 2. 이벤트별 첨부 전략
| 이벤트 종류 | 첨부 여부 | 첨부 기준 |
| --- | --- | --- |
| 수동 푸시 | 전부 전송 (최대 10개) | 주문에 업로드된 전체 이미지/동영상 순차 발송 |
| 실측 완료 | 조건부 전송 | 실측 보고서로 지정된 이미지만 전송 (향후 지원) |
| 도면 확정 | 미전송 | 도면은 링크(ERP)를 통해 직접 확인하도록 유도 |
| 일반 정보 변경 | 미전송 | - |
