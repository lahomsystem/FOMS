# Command Response Contract (CT-D-01)

## 1. 개요
채널톡에서 `/foms` 명령어를 입력했을 때, FOMS 앱 서버가 반환하는 응답 스키마와 규칙을 정의한다.

## 2. 명령어 목록 및 응답 구조

### 2.1 `/foms 주문 {번호}`
- **의도**: 해당 주문의 기본 정보와 현재 상태를 조회
- **응답 템플릿**:
  ```text
  📦 주문 #{order_id} 요약
  - 고객명: {customer_name}
  - 연락처: {phone}
  - 주소: {address}
  - 현재 상태: {status}
  - 수주 제품: {product}
  ```

### 2.2 `/foms 일정 {번호}`
- **의도**: 주문과 관련된 실측/시공/배송 등 핵심 일정 조회
- **응답 템플릿**:
  ```text
  📅 주문 #{order_id} 일정 정보
  - 접수일: {received_date}
  - 실측일: {measurement_date}
  - 시공일: {construction_date}
  ```

### 2.3 `/foms 담당 {번호}`
- **의도**: 주문 처리를 담당하고 있는 팀/매니저 정보 조회
- **응답 템플릿**:
  ```text
  👤 주문 #{order_id} 담당자 정보
  - 담당 매니저: {manager_name}
  - 도면 담당자: {drawing_manager}
  - 시공 담당자: {construction_workers}
  ```

## 3. 에러 핸들링 및 예외 응답
- **포맷 에러**: `/foms 잘못된명령어` -> `[안내] 사용 가능한 명령어: /foms 주문 {번호}, /foms 일정 {번호}, /foms 담당 {번호}`
- **조회 실패**: `[오류] 존재하지 않는 주문 번호이거나 조회 권한이 없습니다.` (HTTP 200 반환 후 텍스트로 에러 표시, 403을 반환할 경우 채널톡 화면에 어떻게 노출되는지에 따라 정책 유동적, 원칙상 Business Conflict는 텍스트로 안내)
- 서버 내부 오류 시에는 채널톡 가이드라인에 따라 HTTP 500 계열을 반환하거나 적절히 로깅한다.
