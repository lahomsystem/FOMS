# WAM Information Architecture (CT-D-02)

## 1. 개요
ChannelTalk WAM (Web App Messenger) 화면의 정보 구조를 정의한다. 1차 구축에서는 **읽기 전용(Read-only)** 모드로만 동작한다.

## 2. 화면 구성 요소

### 2.1 WAM 진입 (Launch)
- **Token 검증**: `?token=...` 파라미터를 통해 WAM Session을 구성한다.
- **초기 로딩 화면**: "주문 정보를 불러오는 중입니다..." 스피너 표시

### 2.2 주문 요약 뷰 (Order Summary View)
- **Header**: 주문 상태 (예: `[실측완료]`, `[시공대기]`) 및 고객명
- **Body**:
  - 주문 번호, 전화번호, 주소
  - 제품 및 옵션 요약
  - 주요 일정 (실측, 시공)
  - 담당 매니저 정보
- **Footer**: 첨부파일 보기 버튼 (클릭 시 2.3 뷰로 이동)

### 2.3 첨부파일 뷰 (Attachment View)
- 주문과 연관된 이미지 및 문서 목록 표시.
- 썸네일을 제공하며, 클릭 시 Presigned URL을 통해 원본을 새 탭에서 열 수 있다.
- 파일 만료 시간에 대한 안내 표시.

## 3. 성능 기준
- WAM 초기 로딩 시간은 5초 이내를 목표로 한다.
- Token 만료 시 또는 권한 없음 시 명확한 에러 메시지를 렌더링한다 ("만료된 세션입니다. 창을 닫고 다시 시도해주세요.")
