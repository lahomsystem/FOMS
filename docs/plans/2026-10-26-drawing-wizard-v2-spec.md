## 2. 데이터(서버 바꾸지 않음)
- 칸은 저장하지 않고 **객체에서 읽는다**: 그림 = `part.label`(V1 닫힌 목록), 자재표 = 첫 줄이 `[SR]` 같은 대괄호 머리글인 글자(V1 `isBomText` 규칙 그대로).
- 특이 사항 · 강조 문구 = 글자 객체이고 **id 앞머리**로 가린다: `n-`(특이 · 실선 = 제작) · `nc-`(특이 · 점선 = 현장/고객) · `st-`(강조 문구). V1 은 id 를 그대로 두므로 V1 에서 열어도 빨간 글자로 보이고(데이터가 숨지 않는다), V1 이 저장해도 역할이 남는다.
- 시트 폼에 문자열 두 칸(서버 `_validate_form` 은 문자열 칸을 받는다, V1 `serializeForm` 은 모르는 칸도 그대로 옮긴다):
  - `v2_layout` = `'band'`(위 띠형) | `'column'`(왼쪽 기둥형) — V2 가 칸으로 정리한 시트 표시. 칸 머리는 이 표시가 있을 때만 그린다. V1 [자동 배치]가 그림을 다시 놓으면 지운다.
    V2 종이에는 V1 의 위쪽 체크 칸·쪽 번호 칸이 없어서 그 자리에 그림·자재표가 놓인다 — V1 에서 이런 시트를 열면 시트마다 한 번 알린다(겹치면 [자동 배치] 또는 새 화면에서).
  - `v2_pick` = 사람이 고른 틀(''|'band'|'column') — 다시 배치해도 그 틀을 쓴다. `v2_photo` = 'done'(실측 사진 자동을 이미 한 시트).
  - `v2_kind` = 제품 종류를 사람이 고른 값('' = 제품 · 시트 이름 글자를 보고 자동 — `detectKind`, 그림은 보지 않는다).
  - `v2_style` = 그림 크기 스타일(''·'hero' 주 그림 크게 기본 · 'even' 고르게, 2026-10-28) — 오른쪽 칸 '그림 크기'에서 시트마다 고른다.
  - `v2_hero_size` = 주 그림 크기 막대 값(고르게 때 높이 대비 %, 없으면 자동, 2026-10-28) — 오른쪽 칸 '그림 크기' 아래 막대.
  - `v2_pin` = 손으로 옮겨 고정한 칸 머리 위 글자 id 를 띄어 쓴 글자(2026-10-28, `v2-text.js`) — 자재표는 한 열만 옮겨도 줄 전체를 적는다. 시트에 없는 글자는 쓸 때 빼고 500자 안. [고정 풀고 모두 다시]가 지운다.
  - `v2_ai` = AI 칸 짐작(2026-10-26 스테이징 피드백 3) — `'<그림 id>=<f|i|d><확신%>'` 를 띄어 쓴 글자(f 정면 · i 입체 · d 상세, 예 `o-ab12=f71 o-cd34=i81`).
    이름표가 미분류(세부 확신 < 문턱)여도 칸 확신(큰 그림 = 정면 + 입체 확률 합, 상세 = 서랍 단면 + 부품 상세 합)이 문턱 이상인 그림만 남긴다.
    서버 `part` 칸은 그대로(이름표는 미분류로 남아 사람이 고르기 전까지 '확인' · V1 '미분류 N장' 칩과 학습 자료 기준이 바뀌지 않는다). 시트에 없는 그림은 쓸 때 뺀다, 폼 한 칸 500자 안.
- 손으로 옮긴 그림 = 지금 자리 ≠ `part.arr`(자동 배치가 놓은 자리, V1 과 같은 뜻). 잠근 그림·돌린 그림은 V1 처럼 옮기지 않는다.
- 켜고 끄기 4개와 V1/V2 선택은 이 브라우저에만 기억한다(localStorage · 쿠키 `dws_ui`).

## 4. 자동 배치(V2) — `v2-slots.js`(묶기) · `v2-layout.js`(틀 계산)
- 칸: 사진(`사진`) · 자재(자재표 글자, 크기 고정) · 특이(`n-`/`nc-` 글자, 줄 바꿈 흐름) · 강조(`st-`, 오른쪽 위) · A 큰 그림(정면·입체 짝 묶음 — V1 `FomsPartLayout.groups` 그대로, 사이드뷰도 정면과 같은 배율로 — 2026-10-28) · B 상세(서랍 단면·부품 상세) · 평면(평면·상판 · 탑뷰 — 2026-10-28) · 미분류(`미분류`·`그림 아님`·종류 없음 — 맨 아래 낮은 줄(높이 170 까지) 또는 오른쪽 좁은 기둥(폭 200 까지) 중 큰 그림이 크게 나오는 쪽의 '기타 그림' 칸, 큰 그림과 배율을 나누지 않는다: 같이 두었더니 한 장만 미분류여도 큰 그림이 반으로 줄었다).
  - 주방(제품 종류)이면 큰 그림을 A 정면 · C 입체 두 칸으로 나눈다.
  - '확신이 낮으면 미분류로' 를 끄면 미분류 그림은 AI 짐작(`part.ai`) 칸으로 간다.
  - 켜 두어도 `v2_ai` 칸 짐작이 있는 미분류 그림은 그 칸에 놓는다(카드 딱지 `정면·도어?` 주황 — 누르면 맨 위 '확인할 그림' 상자의 그 그림으로).
    스테이징 시험(주문 4465, 그림 8장): 세부 확신 0.5 밑 3장 중 2장이 칸 확신 0.71 · 0.81 — 예전엔 셋 다 '기타 그림'으로 갔다.
  - 칸 이름은 칸에 든 그림 종류로 짓는다(처음엔 큰 그림 칸 이름이 제품 이름이라 '주소중복 검증용' 처럼 나왔다): 큰 그림 = `정면 · 입체`(든 것만),
    상세 = `서랍 단면 · 부품 상세`(든 것만), 빈 큰 그림 칸 = 큰 그림(주방은 정면). 내부 · 도어는 머리 오른쪽 작은 글(사람 · 확신 이름표만).
- 틀 두 가지를 모두 계산해 점수가 높은 쪽(사람이 고른 틀이 있으면 그것):

  - 4385 주 그림 크게: 빈칸 16% → 8%, 주 그림 123% → 157%(입체 왼쪽 크게 · 정면 둘 오른쪽 · 상세는 입체 아래), 사진 265px. 4465 사진 2장 띠형: 사진 110px · 글자 8px 밑 → 고르게 모습(사진 244px). 계산은 평균 0.14 → 0.18초.
  - 같은 날 찾은 버그: 같은 그림이 한 시트에 둘(Ctrl+J 사본 — 같은 key)이면 처음 열 때 한 칸이 다음 편집 전까지 빈 틀로 남았다(이미지 캐시가 onload 를 덮어씀, 내보내기 PNG 도 지금 화면을 찍는다) → 기다리는 칸 모두에 넣는다.
  - 같은 시트도 열 때마다 % · 배치가 달랐다: 예전 양식 기준(% 의 분모 — V1 자동 배치 크기)은 치수 글자 높이를 쓰는데, 그림이 뜨기 전에 잰 기준을 계속 기억했다(`v2-shell` baseline 열쇠에 그림 이름 · 크기만). 열쇠에 그림이 떴는지를 넣고, 그림이 다 뜨면 V2 를 한 번 다시 그린다(wizard.js render, 0.15초 묶음).
  - 남은 것: 띠형을 손으로 고르면 특이 사항 밑이 빈다(4385 빈칸 17% — 위 띠 안 빈자리는 채우지 않는다). 추천 틀(기둥형)은 6%.
- 칸 머리 위 글자(2026-10-28 사용자 '자재 입력 시 자동 간격 조절 안 됨' · '특이 사항 추가 시 간격이 자동으로 돌아가 버려' — 질문 창 답 '손으로 벌린 간격이 되돌아감', `v2-text.js`):
  - 글이 바뀌면(자동 배치 · 칸으로 정리한 시트) 그린 뒤 자재표 · 특이 · 강조 글자 크기 지문(id · 폭 · 높이)이 달라졌으면 0.45초 뒤 한 번 다시 배치(쓰는 중 · 끄는 중이면 기다림, 되돌리기는 글 고치기의 한 번). 4385: [SR] 에 1000*2450 을 쓰자 폭 35 → 97px 인데 [EP] 가 그대로 남아 겹쳤다. 색 섞인 글도 그릴 때 폭을 맞춘다(예전엔 끌어야 맞춰졌다).
  - 손으로 옮기면(자동 배치 · '손으로 옮긴 그림은 고정' 켬) 고정(`v2_pin`) — 자재표는 줄 전체, 특이 · 강조는 그 글자. 고정 글자는 장애물이고 그림은 비켜 다시 놓인다('옮긴 글자를 고정했어요 … 풀기 [고정 풀고 모두 다시]'). 고정된 자재표 줄은 글이 길어지면 그 자리에서 앞 열에 붙은 열만 민다(벌린 틈은 그대로). 종이에 작은 '고정' 딱지(화면에만), [고정 풀고 모두 다시 (고정 글자 N)].
  고정끼리 겹치면(같은 날 4385 — 막대 161% 로 나머지가 52×66 까지 작아져 하나를 손으로 키웠더니 다른 고정 그림 위에 놓였고, [다시 자동 배치]는 '이미 놓여 있어요'만 말했다) 배치가 둘 다 안 옮겨 겹친 채 남았다 → 방금 옮긴 그림 · 잠금 · 돌린 그림이 이기고, 겹친 다른 고정 그림은 풀어(지금 자리를 배치 자리로) 비키게 한다(`v2-slots` clashes · release). [다시 자동 배치]도 서로 겹친 고정 그림은 넓이가 작은 쪽을 풀어 다시 놓고 '서로 겹친 고정 그림 N장은 풀어 다시 놓았어요'라고 알린다(푼 것까지 되돌리기 한 번). 겹치지 않은 고정 그림은 그대로.

## 5. 실측 사진 자동
- 시트에 사진 그림이 없고 실측 사진이 있으면, 첫 자동 배치 때 한 장을 골라 넣는다(V1 실측 사진 넣기 API 그대로). 고르는 법: 지금 제품 사진 중 가로 사진 우선, 색·밝기가 가장 고르게 섞인 것(방 전체가 보이는 사진일수록 큼).
- 사람이 지운 뒤에는 다시 넣지 않는다(이 창에서 기억). 사진 칸 카드의 [다른 사진]으로 바꾼다.

## 6. V1/V2 고르기
- 라우트 `/erp/drawing-workbench/<id>/wizard`: `?ui=v1|v2` 가 있으면 그것, 없으면 쿠키 `dws_ui`, 없으면 V1(지금 쓰는 사람 화면은 그대로).
- V1 앱바에 [새 화면 V2], V2 ⋯ 메뉴에 [예전 화면 V1]. 누르면 고치던 것을 자동 저장(PUT)한 뒤 쿠키를 바꾸고 다시 연다.
- 계정마다 기억하려면 DB 칸이 필요하다 — 이번에는 하지 않는다(브라우저마다).
