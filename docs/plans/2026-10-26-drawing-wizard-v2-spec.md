## 2. 데이터(서버 바꾸지 않음)
- 칸은 저장하지 않고 **객체에서 읽는다**: 그림 = `part.label`(V1 닫힌 목록), 자재표 = 첫 줄이 `[SR]` 같은 대괄호 머리글인 글자(V1 `isBomText` 규칙 그대로).
- 특이 사항 · 강조 문구 = 글자 객체이고 **id 앞머리**로 가린다: `n-`(특이 · 실선 = 제작) · `nc-`(특이 · 점선 = 현장/고객) · `st-`(강조 문구). V1 은 id 를 그대로 두므로 V1 에서 열어도 빨간 글자로 보이고(데이터가 숨지 않는다), V1 이 저장해도 역할이 남는다.
- 시트 폼에 문자열 두 칸(서버 `_validate_form` 은 문자열 칸을 받는다, V1 `serializeForm` 은 모르는 칸도 그대로 옮긴다):
  - `v2_layout` = `'band'`(위 띠형) | `'column'`(왼쪽 기둥형) — V2 가 칸으로 정리한 시트 표시. 칸 머리는 이 표시가 있을 때만 그린다. V1 [자동 배치]가 그림을 다시 놓으면 지운다.
    V2 종이에는 V1 의 위쪽 체크 칸·쪽 번호 칸이 없어서 그 자리에 그림·자재표가 놓인다 — V1 에서 이런 시트를 열면 시트마다 한 번 알린다(겹치면 [자동 배치] 또는 새 화면에서).
  - `v2_pick` = 사람이 고른 틀(''|'band'|'column') — 다시 배치해도 그 틀을 쓴다. `v2_photo` = 'done'(실측 사진 자동을 이미 한 시트).
  - `v2_kind` = 제품 종류를 사람이 고른 값('' = 제품 · 시트 이름 글자를 보고 자동 — `detectKind`, 그림은 보지 않는다).
  - `v2_ai` = AI 칸 짐작(2026-10-26 스테이징 피드백 3) — `'<그림 id>=<f|i|d><확신%>'` 를 띄어 쓴 글자(f 정면 · i 입체 · d 상세, 예 `o-ab12=f71 o-cd34=i81`).
    이름표가 미분류(세부 확신 < 문턱)여도 칸 확신(큰 그림 = 정면 + 입체 확률 합, 상세 = 서랍 단면 + 부품 상세 합)이 문턱 이상인 그림만 남긴다.
    서버 `part` 칸은 그대로(이름표는 미분류로 남아 사람이 고르기 전까지 '확인' · V1 '미분류 N장' 칩과 학습 자료 기준이 바뀌지 않는다). 시트에 없는 그림은 쓸 때 뺀다, 폼 한 칸 500자 안.
- 손으로 옮긴 그림 = 지금 자리 ≠ `part.arr`(자동 배치가 놓은 자리, V1 과 같은 뜻). 잠근 그림·돌린 그림은 V1 처럼 옮기지 않는다.
- 켜고 끄기 5개와 V1/V2 선택은 이 브라우저에만 기억한다(localStorage · 쿠키 `dws_ui`).

## 4. 자동 배치(V2) — `v2-slots.js`(묶기) · `v2-layout.js`(틀 계산)
- 칸: 사진(`사진`) · 자재(자재표 글자, 크기 고정) · 특이(`n-`/`nc-` 글자, 줄 바꿈 흐름) · 강조(`st-`, 오른쪽 위) · A 큰 그림(정면·입체 짝 묶음 — V1 `FomsPartLayout.groups` 그대로) · B 상세(서랍 단면·부품 상세) · 평면(평면·상판) · 미분류(`미분류`·`그림 아님`·종류 없음 — 맨 아래 낮은 줄(높이 170 까지) 또는 오른쪽 좁은 기둥(폭 200 까지) 중 큰 그림이 크게 나오는 쪽의 '기타 그림' 칸, 큰 그림과 배율을 나누지 않는다: 같이 두었더니 한 장만 미분류여도 큰 그림이 반으로 줄었다).
  - 주방(제품 종류)이면 큰 그림을 A 정면 · C 입체 두 칸으로 나눈다.
  - '확신이 낮으면 미분류로' 를 끄면 미분류 그림은 AI 짐작(`part.ai`) 칸으로 간다.
  - 켜 두어도 `v2_ai` 칸 짐작이 있는 미분류 그림은 그 칸에 놓는다(카드 딱지 `정면·도어?` 주황 — 누르면 맨 위 '확인할 그림' 상자의 그 그림으로).
    스테이징 시험(주문 4465, 그림 8장): 세부 확신 0.5 밑 3장 중 2장이 칸 확신 0.71 · 0.81 — 예전엔 셋 다 '기타 그림'으로 갔다.
  - 칸 이름은 칸에 든 그림 종류로 짓는다(처음엔 큰 그림 칸 이름이 제품 이름이라 '주소중복 검증용' 처럼 나왔다): 큰 그림 = `정면 · 입체`(든 것만),
    상세 = `서랍 단면 · 부품 상세`(든 것만), 빈 큰 그림 칸 = 큰 그림(주방은 정면). 내부 · 도어는 머리 오른쪽 작은 글(사람 · 확신 이름표만).
- 틀 두 가지를 모두 계산해 점수가 높은 쪽(사람이 고른 틀이 있으면 그것):
  - 위 띠형: 위 띠 = [사진][자재 + 특이][B][평면] (강조는 오른쪽 위), 아래 = 큰 그림 줄.
  - 왼쪽 기둥형: 왼쪽 기둥 = [사진][B][평면], 오른쪽 위 = [자재][특이], 오른쪽 아래 = 큰 그림 줄.
  - 띠 높이·기둥 폭을 여러 값으로 재 보고 고른다. 같은 칸 그림은 같은 배율('같은 칸은 같은 배율'을 끄면 칸 안 그림 높이를 맞춘다). 확대는 원본의 1.25배까지(V1 과 같음).
- 배율(%) = **지금 양식 대비**: 같은 그림을 V1 자동 배치(빈 새 시트 칸)로 놓았을 때 높이에 견준 값. 점수 = 가장 작은 그림 % + 큰 그림 %의 절반, 치수 글자가 8px 밑이면 크게 깎는다.
- 치수 글자가 8px 밑(V1 과 같은 기준)이거나 가장 작은 그림이 60% 밑이면 '시트 2장으로 나누기'를 권한다(처음 80% 로 두었더니 기준인 V1 자동 배치가 빈 종이에 그림을 가득 키운 크기라 그림 넷뿐인 시트에도 권했다 — 로컬 실화면)(큰 그림·상세를 넓이로 반씩 → 새 시트 → 두 시트 모두 다시 배치, 이 시트에서 Ctrl+Z 한 번이면 처음대로).
- 그림 위·안에 붙어 있던 글자·도형·펜(가운데가 그림 안)은 그 그림을 따라 옮긴다(치수 메모가 떨어지지 않게).
- 언제 도나: 자동 배치 모드에서 그림을 올렸을 때(붙여넣기·복제 사본 포함)·종류가 바뀌었을 때(묶음 배치 뒤 30초 넘어 늦게 온 AI 이름표 포함)·**그림을 지웠을 때**·**그림을 손으로 끌거나 키워 고정이 됐을 때**(2026-10-28)·여백을 잘랐을 때·틀/켜고 끄기를 바꿨을 때·[다시 자동 배치]·앱바 [자동 배치]를 눌렀을 때(이미 자동이어도 — 자유 배치에서 손댄 뒤 돌아올 때). 시트를 열기만 해서는 옮기지 않는다(`v2_layout` 없는 시트는 알림 띠로 '정리하기'를 권한다 · 다른 시트에서 끝난 묶음은 그 시트를 열 때 놓는다). 자유 배치 모드에서는 저절로 옮기지 않는다.
  스테이징 주문 4385(2026-10-27): 지우기 사건이 없어(`deleteSelected` 는 render·change 만) 몇 장을 지워도 남은 그림 자리가 비었다 → 코어 사건 `removed`·`trimmed` 를 더했다.
- 되돌리기: 사람이 한 일(올리기·종류 바꾸기·지우기·자르기)과 그 뒤 배치는 Ctrl+Z 한 번에 함께 돌아간다. [다시 자동 배치]·틀 고르기는 따로 한 번. 바뀐 것이 없으면 되돌리기 사본을 남기지 않는다(예전엔 되돌려도 그대로인 헛 한 번이 생겼다).
- 알림: 사람이 누른 배치([다시 자동 배치]·[자동 배치]·정리하기·고정 풀기)는 늘 결과를 말한다 — 다시 놓은 장수 · '이미 칸에 맞게 놓여 있어요' · 고정된 그림 N장은 그대로 · 놓을 자리가 없음. 지운 뒤 배치는 다시 놓았을 때 'N장을 빼고 남은 그림을 다시 놓았어요'. 예전엔 성공해도 알림이 없고 결과가 같으면 화면도 그대로라 '단추가 안 된다'로 보였다.
- [다시 자동 배치]는 오른쪽 칸 바닥(굴러가지 않고 늘 보임, 파란 단추)과 앱바(자동 배치 옆 — 오른쪽 칸이 숨는 1280 밑 창·자재표 계산 칸을 열었을 때도) 두 곳. [고정 풀고 모두 다시]는 고정 그림이나 고른 틀이 있으면 장수와 함께 보인다. '추천' 표시는 점수가 높은 틀(`out.rec`) — 고른 틀과 다를 수 있다. 지금 종이가 낡아 다시 놓으면 크게 커지면(5%p 넘게) 요약·알림 띠가 나누기 대신 '다시 배치하면 32% → 84%'와 [다시 자동 배치]를 권한다.
- 고정 그림 = 장애물: 고정 그림(잠금·돌림·손으로 옮김 — 돌린 모양을 감싼 상자)과 잠긴 자재표·특이·강조는 `input.obstacles` 로 넘기고, 틀은 그것을 뺀 빈 사각형 중 큰 셋 안에서만 재며 장애물에 닿는 틀은 버린다. 예전엔 입력에서 빼기만 해 다시 놓은 그림이 고정 그림 위에 겹쳤다(무작위 시트 200개 중 169개). 잠기지 않은 그 밖 글자·도형은 넣지 않는다(그림을 따라가는 치수 메모가 장애물이 되면 칸이 잘게 쪼개진다). 고정 그림은 칸 머리 자리에서 빼고, 종이 위 왼쪽 위에 '고정' 표시(화면에만)를 띄운다.
- 사람이 '옮겼다'고 느끼지 않는 고정을 줄였다: 옮김은 6px 넘게만 친다(Konva 는 3px 부터 끌기 — 1px 로 재던 때는 그림을 누르다 손이 조금 밀려도 고정), 붙여넣기·Ctrl+J 사본은 `part.arr` 를 지워 새 그림으로(예전엔 어긋나게 놓은 사본이 처음부터 고정), 배치 자리에 있던 그림의 여백 자르기는 새 크기를 `part.arr` 로 남긴다.
- 칸 머리: 띠 칸·자재 칸·오른쪽 좁은 미분류 기둥은 머리 최소 폭(132px)만큼 자리를 잡는다(좁은 칸 머리가 옆 칸 머리 위로 뻗었다). 배율 표시(화면에만)는 머리 오른쪽 끝 위에 띄워(아래 끝 = 머리 글 윗선) 칸 이름을 가리지 않는다 — 예전엔 머리 가운데에 걸쳐 'B 서랍 단면 · 부[32%]세'처럼 가렸다.
- 사람이 종류를 고르면(자동 배치 모드) 그 그림의 고정(손으로 옮김)을 풀어 새 종류 칸으로 보낸다 — 잠금 · 돌림은 그대로. 스테이징 피드백 2:
  기타 그림 줄의 그림을 조금 옮긴 뒤(크기 88→84) 종류를 골랐더니 '고정'이라 그 자리에 남아 '자동 정렬이 안 된다'로 보였다.
- 주 그림 크게(bento — 2026-10-28 사용자 요청 '메인 컴퍼넌트를 크게', 켜고 끄기 '주 그림 크게' 기본 켬, `v2-hero.js`): 틀을 고르고 추천까지 정한 뒤
  큰 그림 칸(장애물을 비켜 간 자리)만 다시 놓는다 — 원본 넓이가 둘째의 1.3배 넘는 묶음을 주 그림으로 크게, 나머지는 남은 자리에 같은 배율로
  (주 그림 왼쪽 + 나머지 오른쪽, 주 그림 위 + 나머지 아래 중 주 그림이 큰 쪽). 나머지 배율은 주 그림의 절반 이상이고 치수 글자 8px ·
  지금 양식 대비 60% 밑으로 줄이지 않는다(이미 밑이면 더 줄이지 않음). 주 그림이 1.15배 넘게 커질 때만 바꾼다. 비슷한 묶음끼리는 하나만 키우지 않는다.
  주방(정면 · 입체 두 칸)은 주 그림이 제 칸에 혼자일 때만 — 칸 머리는 칸마다. 큰 그림 칸 배율 표시 · 틀 후보의 '큰 그림 %'는 주 그림 %.

## 5. 실측 사진 자동
- 시트에 사진 그림이 없고 실측 사진이 있으면, 첫 자동 배치 때 한 장을 골라 넣는다(V1 실측 사진 넣기 API 그대로). 고르는 법: 지금 제품 사진 중 가로 사진 우선, 색·밝기가 가장 고르게 섞인 것(방 전체가 보이는 사진일수록 큼).
- 사람이 지운 뒤에는 다시 넣지 않는다(이 창에서 기억). 사진 칸 카드의 [다른 사진]으로 바꾼다.
