# T4 — 네이버 상태 동기화 버튼 (설계 판정)

작업 트리: `c:\tmp\nvfix`. **이 task 는 설계다 — 코드를 쓰지 마라.** 결과물은 판정과 설계서다.

## 사용자 지시 (원문)

> "네이버와 주문확인, 발송처리, 취소 반품 등 동기화를 버튼을 통해 할 수 있게 해봐 (가능하면)"

"(가능하면)" 이 붙어 있다 — **못 하거나 하면 안 되는 것이 있으면 그렇게 판정하는 것도 답이다.**

## 먼저 확인해야 할 것: 지시의 뜻이 갈린다

같은 문장이 두 가지로 읽힌다. **어느 쪽인지 코드를 읽고 판정하고, 근거를 대라.**

- **읽기(pull)**: 네이버에서 그 집의 **최신 상태를 다시 받아** FOMS 화면을 갱신한다.
  판매자센터에서 일어난 취소·반품·발송이 우리 화면에 늦게 반영되는 문제를 푼다. 되돌릴 수 있다.
- **쓰기(push)**: 발주확인·발송처리·취소를 **네이버로 보낸다**. 이건 **이미 있다**
  (워크벤치 처리 탭의 버튼 4종). 그렇다면 지시는 "없는 것을 만들어라" 가 아니라
  "안 보이는 자리에서도 되게 해라" 일 수 있다.

둘 다일 수도 있다. 판정하고, 갈리는 지점을 사용자에게 물어야 한다면 **무엇을 물어야 하는지**를
한 문장으로 써라.

## 알고 가야 할 제약 (전부 근거가 코드에 있다 — 확인하고 라인을 달아라)

1. **네이버로 나가는 HTTP 는 WORKER 에서만.** web 은 enqueue 만 한다(호출 IP 화이트리스트 계약).
   `foms/services/jobs/queue.py` 의 `enqueue_naver_order_sync` · `enqueue_naver_fulfillment` 주석.
2. **`지금 수집` 은 워터마크 기반이라 신규만 긁는다.** 이미 수집된 집의 상태 변화를 다시 읽는
   경로가 지금 있는지 없는지 확인하라 —
   `foms/services/integrations/naver_commerce/` 의 `ingest.py` · `watermark.py` · `claim_watch.py`.
   **`claim_watch.py` 를 반드시 읽어라.** 이미 클레임 감시가 있다면 이 지시의 절반은 이미 있는 것이고,
   그렇다면 "버튼으로 부를 수 있게" 만 하면 된다 — 새 수집 경로를 만드는 것보다 훨씬 작다.
3. **되돌릴 수 없는 호출과 읽기 호출을 섞지 마라.** 발주확인·발송처리·취소는 불가역이고 모달로
   재진술한 뒤에만 나간다. 동기화가 읽기라면 그 모달이 필요 없고, 오히려 붙이면 사람이 무뎌진다.
4. **이력 표에는 처리 버튼을 두지 않는다**(절대 규칙 3). 허용되는 모양은 평범한 링크뿐이다.
   오늘 만든 `원본 보기` 가 그 예다(`templates/admin/naver_workbench.html` 의 `wb-hist-detail`).
5. **조용히 성공한 척 금지.** 큐가 없으면 화면이 그렇게 말해야 한다(`naver_ingest_run_now` 참고).
6. **워커 동시성 1 · 워터마크 60초 벽** — 눌러도 즉시 반영이 아니다. 오늘 `지금 수집` 은
   지문(`rev`) 폴링으로 이 문제를 풀었다(`_watermark_rev` · `run-state`). 같은 장치를 쓸 수 있는지 보라.
7. **레이트 리밋·API 쿼터** — 집 단위로 아무 때나 다시 읽으면 네이버 호출이 몇 배가 된다.
   실제 상한이 코드·문서에 있는지 확인하고, 없으면 "확인 못 함" 이라고 써라.

## 답해야 할 것

1. **지시의 뜻 판정** (읽기 / 쓰기 / 둘 다) — 근거 `파일:라인`.
2. **이미 있는 것과 없는 것** — 표로. "이건 이미 됩니다" 를 먼저 말하는 것이 이 판정의 값어치다.
3. **설계안** — 없는 것만. 각 조각마다 *어디에* 놓을지(경로·파일)와 *왜 거기*인지.
   불가역 호출이 새로 생기면 그 사실을 맨 앞에 써라.
4. **범위 판정** — 셋 중 하나:
   - **지금 하자**(작고 위험이 낮다 — 근거)
   - **쪼개서 하자**(1단계는 이것, 나머지는 나중 — 경계와 이유)
   - **하지 말자**(이미 있거나, 위험 대비 값어치가 없다 — 근거)
5. **사용자에게 물어야 할 것** — 있으면 **한 문장 질문 1개**로. 없으면 "없음".

## 하지 말 것

- 코드·테스트 파일 편집 금지.
- 스테이징·운영 접속 금지.
- "구현하면 됩니다" 로 끝내지 마라. 이 판정의 값어치는 **안 만들어도 되는 것을 찾아내는 것**이다.
