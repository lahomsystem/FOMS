# 도면 마법사 저장 창 — 전달본과 달라진 다른 시트도 함께 보내기 — 설계서

- 상태: 승인 (2026-11-06)
- 앞 설계서: `docs/specs/2026-11-05-wizard-save-send-options_SPEC.md` (저장 창), 같은 날 고친 것 (대기함의 다른 시트도 함께 보냄, 운영 PR #751)

## 1. 왜 (운영 주문 5862, 2026-11-06 확인)

4장짜리 주문을 11-03 에 일괄 전달했다. 그 뒤 도면팀이 시트 몇 장을 고쳤다.

| 시트 | 고친 뒤 [저장] | 전달본 |
|---|---|---|
| 몰딩 신발장 | 했다 (10:26 · 11:06) | 고친 그림 ✔ |
| 슬라이딩 붙박이장 | 했다 (09:55) | 고친 그림 ✔ |
| 몰딩수납장 | 고친 것 없음 | 11-03 그대로 (맞음) |
| **몰딩 미드웨이 수납장** | **안 했다** — 자동 저장만 됨 (그림 13 → 17개, 현장규격 · 발주 리스트 칸 바뀜) | **11-03 옛 그림** ✘ |

자동 저장은 작업 내용만 서버에 적고 그림(PNG)은 만들지 않는다. 그래서 다른 시트에서 [저장 + 전달 + 도면방]을 눌러도
미드웨이 수납장은 11-03 그림이 그대로 영업 · 도면방에 나갔다. 오늘 고친 것(대기함의 다른 시트도 함께)으로는 못 잡는다 —
이 시트는 대기함에 들어간 적이 없기 때문이다.

다시 연 화면도 이것을 모른다. 지금 화면은 "이 시트가 전달본과 달라졌나"를 그 창 안에서만 기억한다(전달본에는 그림 지문이 남지 않는다).

## 2. 무엇을 바꾸나

### 2.1 서버 — 전달본에 그림 지문을 남긴다

- [저장]은 이미 대기함 항목에 그림 지문(`sig`, `v2:` 판)을 남긴다. 전달할 때 이 지문을 **전달본 항목(`drawing_current_files`)에도 옮겨 적는다.**
  `/transfer-drawing`(대기 시트 병합)과 `/drawing-wizard/transfer-pending` 두 길 모두. 모양이 틀린 지문은 버린다(지금 대기함과 같은 검사).
- `GET /drawing-wizard/pending` 응답에 `current: [{sheet_id, sig}]`(지금 전달본의 시트별 지문, 없으면 `null`)를 **더한다.** 기존 `pending` 은 그대로.
- 새 API 없음. 저장 모양은 항목에 키 하나(`sig`)가 늘 뿐이다.

### 2.2 화면 — [저장] + 발송 때 달라진 시트를 다시 그려 함께 보낸다

[저장](한 장) + 발송을 누르면:

1. 지금 시트를 저장한다(지금처럼).
2. 대기함 · 전달본 지문을 다시 읽는다(`GET /pending`).
3. 다른 시트를 이렇게 나눈다.
   - 대기함에 있다 → 함께 보낸다 (오늘 고친 것 그대로)
   - 전달본이 있고, 지문이 지금 시트 내용과 같다 → 그대로 둔다
   - 전달본이 있고, **지문이 다르거나 없다**(옛 전달본) → **그림을 다시 만들어 대기함에 넣고** 함께 보낸다
   - 전달본도 대기함도 없다(한 번도 안 보낸 새 시트) → 건드리지 않는다. 아직 그리는 중일 수 있다. 보내려면 그 시트에서 [저장]
4. 모두 `APPEND` 로 한 번에 전달 → 도면방 PUSH(켰으면).

- 다시 그리는 동안은 일괄 저장처럼 시트를 넘기며 그린 뒤 원래 시트로 돌아온다. 한 장이라도 못 그리면 **전달하지 않는다**(일괄 저장과 같은 규칙).
- 끝 알림: `저장했어요 · 영업에게 3장 전달했어요 (고친 다른 시트 1장 포함)`.
- [일괄 저장] + 발송은 지금도 모든 시트를 다시 그리므로 바꾸지 않는다.
- 발송을 끈 [저장]만은 지금처럼 지금 시트만 넣는다.

### 2.3 한 번은 모두 다시 그려진다

지금 운영 전달본에는 지문이 없다. 그래서 고친 뒤 처음 발송할 때는 **전달본이 있는 다른 시트를 한 번씩 모두 다시 그려** 보낸다
(내용이 같아도 새 파일로 바뀐다). 그다음부터는 달라진 시트만 다시 그린다. 이것을 피하려고 옛 전달본을 서버에서 대조하는 것은
그림 파일 · 버전 기록을 읽어야 해서 무겁고 틀릴 수 있다 — 한 번 다시 그리는 쪽이 확실하다.

## 4. 하지 않는 것

- 자동 저장이 그림까지 만들게 하기 (45초마다 그림을 만들면 무겁다).
- 앱바 칩이 다시 연 창에서도 "전달본 예전 것"을 보여 주기 — 같은 지문으로 할 수 있지만 이번 범위 밖. 원하시면 이어서.
- 운영에 이미 나간 옛 그림 정리 (5862 미드웨이 수납장은 고친 뒤 도면팀이 한 번 더 보내면 바뀐다).
