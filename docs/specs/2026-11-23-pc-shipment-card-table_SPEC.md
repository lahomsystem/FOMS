# PC 출고 탭 — 표 안쪽만 태블릿 모양으로 (2026-11-23)

상태: 2026-11-23 목업 승인("내부만 바꿔" → "이대로 만들기 시작") · 설계 승인 · 구현(로컬 실화면 통과, 스테이징 확인 전)
목업: `docs/design/mockups/pc-shipment-tablet-interface.html`
선행 설계서: `docs/specs/2026-11-09-tablet-production-ui_SPEC.md` §14.3(태블릿 하루치 출고표)

## 1. 왜

PC 출고 탭(`/erp/shipment`)의 표는 세로 칸 선이 많고 시공자 묶음이 눈에 안 들어온다. 태블릿 출고표는 시공자별
묶음 카드 · 사람 색 덩어리 · "시공자 없음" 맨 위라 누가 어디 가는지 한눈에 보인다. PC 표 안쪽을 그 모양으로 바꾼다.

쓰는 사람: 출고 담당 · CS(PC · 마우스 · 화면 크기 80%). 하루 일 = 시공자 넣기, 시공시간 · 현장 메모 쓰기.

## 2. 안 바꾸는 것 (사장님 2026-11-23 "내부만", 남길 것 셋)

- 머리줄 · 검색 · 기준 날짜 · [조회] · [AS일정 추천]
- 왼쪽 "날짜별 시공" 14일 목록, "날짜별 잔여 시공"(자수 · **인원**)
- **칸 너비 끌어서 바꾸기**
- 시공일 바뀜 알림 줄 · 협력사 희망 판 · 이미지 저장
- 표에서 바로 쓰기: 시공시간 · 도면 담당 · 현장 메모(색)
- 글자 · 단추 크기(줄이지 않는다)
- 태블릿 · 폰 화면

## 3. 바꾸는 것 (표 안쪽)

| 번호 | 무엇 | 지금 | 바꾼 뒤 |
| --- | --- | --- | --- |
| 1 | 묶음 | 한 표에 줄이 이어짐 | 시공자별 흰 카드로 끊어 보임 |
| 2 | 시공자 없음 | 이름순 맨 끝 | 맨 위 · 옅은 빨간 테두리 · "시공자 없음 n건" |
| 3 | 칸 선 | 세로 선 있음 | 세로 선 없음 · 가는 가로 선만 |
| 4 | 시공자 칸 | 칸 전체 색 + 글자 입력 | 사람 색 덩어리(같은 사람 줄끼리 위아래로 붙음), 두 명이면 위아래 반씩 |
| 5 | 시공자 넣기 | 칸에 이름 치기 | 칸을 누르면 이름판(건수 · 자수 보임, 여러 명, 직접 쓰기 · 비우기) |
| 6 | 첫 칸 | "상세"(연필) | "번호" + 연필 |
| 7 | 줄 누르기 | 없음 | 오른쪽에 세부 창(전화 복사 · 지도 · 품목 · 시공시간 · 현장 메모) |

## 4. 어떻게 만드나

핵심: **PC 표(`#shipment-dashboard-table`)를 그대로 두고 모양만 바꾼다.** 태블릿 출고표로 갈아 끼우지 않는다 —
PC 표에 붙은 기능(바로 쓰기 · 칸 너비 · 이미지 저장 · AS 추천 · 시공일 바뀜 줄 찾아가기)이 전부 이 표의 줄을 읽기 때문이다.

### 4.1 1단계 — 카드 모양 · 사람 색 · 이름판
- 줄 순서: 하루를 볼 때 서버가 태블릿과 같은 묶음 순서(`build_tablet_day_sheet`: 시공자 없음 → 설정 순 → 그 밖)로 줄을 낸다.
  묶음마다 `<tbody>` 하나. 여러 날 · 검색 결과는 지금 순서 그대로(카드 모양만).
- 번호 · 사람 색 번호는 `build_tablet_day_sheet` 결과를 그대로 쓴다(새 쿼리 없음, 태블릿과 같은 번호 · 같은 색).
- 모양은 새 CSS 파일 하나(`static/css/contexts/shipment/pc-card-table.css`), 문지기 = PC(터치 아님 · 992px 이상).
  태블릿 · 폰 규칙은 손대지 않는다.
- 칸에 박힌 세로 선 인라인 스타일을 걷어 낸다(인라인 스타일 줄이기 래칫에도 맞다).
- 시공자 칸: 단추(`data-ship-worker-cell`)로 바꾸고 태블릿 이름판 스크립트(`tablet-ship-assign.js`)를 PC 에서도 쓴다.
  이름판 모양 규칙을 PC 문지기에도 건다. 저장 길은 지금과 같은 `/api/erp/shipment/update/<id>`(서버 무변경).
  이름판을 닫으면 그날 화면을 다시 받아 묶음 · 색을 서버가 다시 정한다(태블릿과 같음).
- 시공자 칸 글자 입력 · "저장된 값 불러오기"는 이름판의 [직접 쓰기]가 대신한다.

### 4.2 2단계 — 줄 누르면 오른쪽 세부 창
- 줄에는 이미 세부 주소(`data-foms-sheet-url` → `tablet_sheet.html`)가 있다. PC 용 작은 스크립트가 그 조각을 오른쪽 창에 띄운다.
  태블릿 공용 시트 스크립트(`tablet-side-sheet.js`, 수정 금지 · 터치 전용 문지기)는 건드리지 않는다.
- 입력 칸 · 단추 · 링크 · 바로 쓰기 칸을 누른 것은 줄 누름으로 치지 않는다.
- PC 에서는 "전화 걸기" 대신 "복사", 창 위에 "주문 열기". 저장은 태블릿 시트와 같은 길(시공시간 · 현장 메모만).
- Esc · 바깥 누름으로 닫기, 열린 동안 ↑↓ 로 줄 옮기기.

### 4.3 서버 · DB
DB · API 변경 없음. 라우트는 줄 순서와 묶음 정보만 템플릿에 더 넘긴다.

## 5. 확인

- 시험: 줄 순서(시공자 없음 맨 위 · 태블릿과 같은 번호), 시공자 칸 단추 자료, 인라인 선 스타일 0, PC 문지기 밖 규칙 무변경.
- 실화면(스테이징, `claude_master`): 2400×1188(80%) · 1920 · 1366 에서 가로 넘침 없음, 고치기 전후 글자 · 단추 크기 같음.
  바로 쓰기 셋 · 칸 너비 끌기 · 이미지 저장 · AS 추천 · 시공일 바뀜 [확인] · 이름판 넣기/빼기/직접 쓰기 · 세부 창 저장.
  태블릿(터치 가로) · 폰 화면이 전과 같은지 대조.
- 올리기: deploy(스테이징)까지. 운영은 따로 말씀하실 때.

## 6. 정한 것 (사장님 2026-11-23)

- D1 시공자 넣기: **이름판에 글자 입력 가능하게** — PC 이름판은 글자 입력 칸이 처음부터 열려 있다([직접 쓰기] 단추 없음).
  시공자 칸의 옛 글자 입력은 PC 카드 모양에서 숨는다.
- D2 줄 누르면 세부 창: **같이 만든다**.

## 7. 만들면서 정한 것

- 세부 창은 **현장 메모를 고치지 않는다**(읽기만). 태블릿 세부 창의 저장은 메모를 한 줄로 덮어쓰는데 PC 표는 메모가 여러 줄 · 색이라
  덮어쓰면 지워진다. PC 는 지금처럼 표의 주소 칸에서 고친다. 세부 창 저장은 시공시간만 보낸다.
- 세부 창은 표 위에 겹쳐 오른쪽에 뜬다(표 폭을 줄이지 않는다 — 칸 너비를 사용자가 정해 둔 표라 밀면 가로 스크롤이 생긴다).
- 글자를 끌어 고른 채 줄을 누르면 세부 창을 열지 않는다(주소 복사 방해 금지).
- 줄 순서는 표에서만 바뀐다(시공자 없음 맨 위 · 한 시공자의 AS 줄은 그 카드 끝). 이미지 저장은 표를 읽으므로 같은 순서로 나온다.
- 문지기 = 마우스 · 992px 이상. 그 밖(터치인데 태블릿 화면이 아닌 경우 · 좁은 창)은 예전 표 모양 · 예전 시공자 글자 입력 그대로.
