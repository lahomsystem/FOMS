## 문제 (사용자 신고 4건 → 구조 진단)

태블릿(가로, ≥992px, pointer:coarse) 도면 작업실에서:
1. 주문 타일 흐림 — `is-dim`(opacity 0.55)이 `TRANSFERRED`(확정 대기)에도 적용, 화면 대부분 카드가 해당 상태라 대시보드 전체가 바랜 듯 보임 (`templates/drawing/partials/tablet_gallery_body.html:102`, `static/css/foundation/foms-tablet-drawing-gallery.css:458`, `:712`)
2. 도면 클릭 불가 — 카드 탭은 사이드 시트만 열고(`static/js/foms/tablet-side-sheet.js:414-429` preventDefault), 시트 썸네일 스트립(120×84)은 순수 `<img>`로 확대 수단 전무. 태블릿 표면에만 뷰어 미배선
3. 썸네일 크롭 — thumb 고정 `height:132px` + `object-fit:cover`, aspect-ratio 없음 (`foms-tablet-drawing-gallery.css:105-115`). 크기 토글은 폭만 변경(220/260/320px)이라 "크게"일수록 크롭 심화
4. 실행판("원 주문") PC 레이아웃 — `templates/drawing/partials/workbench_detail_body.html` **인라인 `<style>`**(73-78행)의 `1.7fr/1fr` 그리드, breakpoint는 992px 1종뿐 → 992~1366px 태블릿 가로는 PC 그대로

구조 진단: 태블릿 갤러리가 "관리 리스트 표면"으로 설계돼 도면 자체가 1급 객체가 아님. 현장 앱 표준(PlanGrid·Fieldwire 등)은 도면 탭 → 전체화면 핀치줌 뷰어가 코어 인터랙션.

## Vision

### 10x Check
담당자가 태블릿을 들고 갤러리를 연다. 급한 건(D-1 이하)이 테두리로 빛난다. 카드를 탭하면 도면이 전체화면으로 뜬다 — 핀치로 치수 확대, 좌우 스와이프로 시트 넘김. 하단 오버레이에서 바로 수령 확정 또는 수정 요청(사유 칩+텍스트). 판정하면 자동으로 다음 확정대기 주문 도면으로 전환. 확정대기 건을 앉은 자리에서 완주 — 화면 이동 0회. (현재: 건당 2~3회 페이지 이동)

### Platonic Ideal
종이 도면 뭉치를 손으로 넘기는 감각. 도구가 사라지고 도면만 남는다. 갤러리 = 오늘의 도면 스택, 뷰어 = 판정대, 실행판 = 깊은 검토실(타임라인·주문변경·버전비교). 세 표면이 하나의 여정.

## Accepted Scope (구현 명세)

### E1. 갤러리 코어 수정
- **is-dim 완전 삭제** (조건 축소 아님). 근거: 상태 구분은 "확정 대기" 칩·thumb-label이 이미 제공하고, dim은 확정대기(=리뷰 대상) 카드를 비활성처럼 보이게 하는 역정보. 태블릿 필터바에 `include_confirmed` 토글이 없어(`tablet_gallery_body.html:51-76`) 통상 CONFIRMED 미유입이나, **딥링크 `?include_confirmed=1`은 서버가 수용**(`foms/web/drawing/workbench.py:268,311-319`) — 그 경우에도 칩으로 충분히 구분됨. 삭제 대상: `tablet_gallery_body.html:102` 조건, `foms-tablet-drawing-gallery.css:458-460`, `:711-714`.
- **계약 테스트 수정 필수**: `tests/domains/test_tablet_drawing_workshop_contract.py:108`의 `assert "is-dim" in body`가 **실패하게 됨** → 해당 assertion 삭제 + `assert "is-dim" not in body`로 대체. (109행 `'TRANSFERRED', 'CONFIRMED'` assertion은 템플릿 112행 thumb-label 리터럴로 계속 통과 — 유지.)
- 썸네일: `.foms-drawing-gallery-card__thumb` `height:132px` → `aspect-ratio: 4/3; max-height: 180px`. **의도된 트레이드오프**: lg(320px 컬럼)에서는 캡이 이겨 실효 비율 ≈16:9 — 세로 도면은 contain 좌우 레터박스 심화. 스캔 밀도(한 화면 카드 수) 보호가 우선. `.foms-drawing-gallery-card__img` `object-fit: cover` → `contain`, 배경은 기존 `--foms-surface-muted` 유지(흰 배경 금지 — 선도면에서 카드 경계 소실).
- 시트 스트립(120×84)은 변경하지 않음 (신고 범위 밖 + 미전달 autosave 표면).

### E2. 도면 전체화면 뷰어 배선
- **서버 변경(소폭) 포함**: `foms/web/drawing/workbench.py` rows에 3필드 추가:
  - `drawing_files`: **`_is_image_file` 필터 통과분만** — 각 `{key, view_url, download_url, filename}`. 비이미지(PDF 등) 전달본은 뷰어·판정 대상에서 제외됨을 **부작용으로 기록**(비이미지만 있는 주문은 카드 탭=시트 폴백). 루프 지역변수(`:353`) 재사용, 신규 쿼리 0.
  - `can_confirm_receipt_perm`: **순수 권한 플래그**(상태 미포함) — **[D7 정정]** rows 루프의 기존 `can_sales`(`:377`, 주문별: 배정자+이름 폴백) 재사용: `is_admin or (can_sales and not is_drawing_team)`. `is_admin`/`is_drawing_team`은 요청당 1회 계산(상세 라우트 `:717` 로직과 동일 조건 — `not is_drawing_team` 누락 금지: 누락 시 상세에선 숨는 버튼이 태블릿에서만 노출). **이름 주의**: 상세 라우트의 `can_confirm_receipt`(`:718-721`)는 상태 합성형(템플릿 `:1503`이 상태 검사 없이 사용) — 동명 재사용 금지.
  - `can_request_revision`: 동일 공식 `is_admin or (can_sales and not is_drawing_team)` (상세 라우트 `:717` 주석 그대로 "영업측 전용(도면팀에는 안 보임)"). 주문별 판정이므로 남의 주문 카드엔 버튼 미노출(403 벽 방지).
- URL 해석: `resolve_row_thumbnail_url`(`foms/services/drawing_workbench_display.py:46-95`)에서 `resolve_row_image_list()` 도출 — **기존 행당 1회 조회를 재사용해 목록 반환**(파일마다 재조회 금지). 머지 전 도면 대시보드 TTFB + EXPLAIN.
- 카드 썸네일 탭 배선 (a11y 결함 회피 — `<a>` 내부 interactive 중첩 금지):
  - `__thumb`에 **`data-foms-drawing-viewer` 데이터 속성**(role/tabindex 부여 금지 — `<a>` content model 위반·포커스 트랩 방지).
  - `tablet-side-sheet.js` 클릭 가드에 분기 1줄: `target.closest('[data-foms-drawing-viewer]')`면 early-return(시트 미개방).
  - **신규 썸네일 핸들러는 `ev.preventDefault()` 필수** — 앵커 네비 차단 책임이 side-sheet(`:426`)에서 이관됨. 누락 시 썸네일 탭이 상세 페이지 풀 로드.
  - 키보드 접근성: 썸네일 탭은 포인터 전용. 키보드 사용자는 카드 앵커(기존 fallback → 상세 페이지) 경유 — 동등 기능 대체 경로 존재를 명시.
- **[딥리뷰 5A] 신규 로직 소속 = `static/js/foms/tablet-drawing-review.js` 신설** (배선·판정·연속 플로우 전담). `tablet-drawing-gallery.js`는 무변경 목표(크기토글·롱프레스 계약 유지 — 무변경이면 `:122` 버전핀 범프 불필요). `?v=` 범프는 실제 수정 파일에만.
- 리스너 구조 확정: **갤러리 컨테이너 요소에 위임 리스너 1개**(document 레벨 아님). fragment 재실행 대비 `window.__FOMS_DRAWING_VIEWER_BOUND` 싱글톤 가드(G4). 참고: `tablet-drawing-gallery.js`는 perf baseline(`FRAGMENT_REPLAYED_GLOBAL_LISTENER_BASELINE`) 비등재 파일 — 가드가 자동으로 잡아주지 않으므로 컨테이너 스코프+싱글톤을 계약 테스트로 잠금.
- 롱프레스 다중선택(capture 단계 `stopPropagation`+`consumeNextClick`, `tablet-drawing-gallery.js:264-303`)과 순서 무충돌 — capture가 먼저 소비.
- `thumbnail_url` 없는 카드(이미지 도면 0장): `data-foms-drawing-viewer` 미부여(시트 열기 유지) + "도면 없음" 플레이스홀더 라벨.
- 시트 스트립 탭: 소스가 다름 — 스트립 = 마법사 미전달 자동저장 PNG(`foms/web/drawing/tablet_sheet.py:101-111`, `_pending_list`). 열람용 GlobalImageViewer만(옵션 없이) 배선, **판정 오버레이 미노출**.
