# AS 줄 시공자 비우기 · 출고 설정 AS 기사 (2026-11-23)

상태: 2026-11-23 사장님 요청 · 정할 것 셋 답 받음 · 구현 · 운영 PR #907(2026-11-23) · 옛 AS 줄 8건 비움(운영, 출고 저장 길로 — 접수 뒤 고친 15건 · 건 기록 없는 1건은 그대로)
요청 원문: "출고에 AS 기사가 별도 있어서 출고 설정에 별도 넣어야 되고, 출고 스케줄에는 erporder 시공자가 들어가 있는데,
AS는 시공자 또는 다른 시공자가 배치될 수 있어 비워놔"

## 1. 지금

- 주문마다 시공자 칸이 하나(`structured_data.shipment.construction_workers`)다. 시공과 AS 방문이 이 한 칸을 같이 쓴다.
- 그래서 AS 를 접수해도 원래 시공자가 그대로 남아, 출고 스케줄의 AS 줄에 원래 시공자가 보인다.
- 이 칸은 "지금 맡은 사람" 뜻으로 쓰인다: AS 탭 시공자 칸에서 고치고, 시공 탭 · 시공 완료 화면의 "내 것" 거르기, AS 알림 글의
  "시공자 -" 줄, 출고 표 묶음 · 사람별 건수가 모두 이 칸을 읽는다. AS 줄만 따로 다루는 곳은 없다.
- 이 칸이 AS 때 채워지는 길 둘:
  - 시공 탭에서 시공자가 직접 AS 를 접수하면 **접수한 사람 이름**으로 덮어쓴다(`foms/api/cs/as_orders.py:670-674`).
  - 출고 탭 [AS일정 추천]으로 AS 를 출고 줄에 붙이면 **그 출고 줄 시공자**를 AS 주문에 복사한다
    (`foms/services/shipment/as_recommendation.py:326-359`).
- 출고 설정의 사람 목록은 시공자 하나뿐이다(이름 · 하루 자수 · 쉬는 날). AS 탭 · 출고 탭의 고르기 목록도 이것이다.

## 2. 바꾸는 것

### 2.1 AS 를 접수하면 시공자 칸을 비운다
- 새 AS 건이 시작될 때(어느 화면에서 접수하든) 시공자 칸을 비운다. 비우기 전 값은 그 AS 건에 남겨 두어
  [접수 취소]가 원래 시공자로 되돌린다(지금 있는 되돌리기 길 그대로, `as_cycle_cancel.py`).
- 다시 접수(이미 AS 중인 주문에 한 번 더 접수)는 건드리지 않는다 — 이미 정해 둔 AS 담당을 지우지 않는다.
- **시공이 아직 남은 주문**(생산 · 시공 진행 중에 AS 가 접수된 주문)은 비우지 않는다 — 남은 시공일의 시공자가 지워지면 안 된다.
- 비운 뒤에는 출고 스케줄 AS 줄이 "시공자 없음" 묶음(맨 위)에 뜬다. 거기서 이름판으로 넣는다.
- 원래 시공자가 누구였는지는 주문 변경 이력에 남는다(지금도 이 칸이 바뀌면 이력 한 줄이 남는다).

### 2.2 출고 설정에 AS 기사 목록
- 출고 설정에 "AS 기사" 칸을 새로 둔다. 이름만 적는다(AS 는 자수를 안 세므로 하루 자수 없음).
- AS 기사가 보이는 곳:
  - 출고 스케줄 **AS 줄**의 이름판: AS 기사 먼저, 그 아래 시공자. 둘 다 고를 수 있다.
  - AS 탭 시공자 칸의 고르기 목록: 시공자 + AS 기사.
- 시공 줄의 이름판에는 AS 기사를 넣지 않는다. 날짜별 잔여 자수 · 인원 계산에도 넣지 않는다(시공자만 센다).
- 저장 자리: 지금 출고 설정 값(`erp_shipment_settings`)에 `as_technicians` 목록 하나를 더한다. DB 표 · 칸 추가 없음.

## 3. 안 바꾸는 것

- 시공자 칸은 그대로 하나다(AS 담당 칸을 따로 만들지 않는다). 이 칸을 읽는 30여 곳(AS 탭 · 시공 탭 · 알림 · 이력)이 지금처럼 돈다.
- AS 탭에서 시공자 칸을 고치는 길, 출고 탭에서 고치는 길.
- 잔여 자수 · 인원 계산.

## 4. 정한 것 (사장님 2026-11-23)

- D1 이미 접수돼 있는 AS 줄: **한 번에 비운다.** AS 접수 뒤에 누가 시공자 칸을 고친 적이 없는 주문만(고친 적 있으면 일부러 넣은
  AS 담당이다). 운영 자료를 고치는 일이라 먼저 몇 건인지 세어 보여 드리고 한다.
- D2 시공 탭에서 시공자가 직접 AS 를 접수할 때: **이것도 비운다**(접수한 사람 이름을 넣지 않는다).
- D3 [AS일정 추천]으로 출고 줄에 붙일 때: **지금처럼 그 줄 시공자를 넣는다.**

## 5. 확인

- 시험: 접수 때 비움 · 접수 취소 때 되돌림 · 다시 접수는 안 건드림 · 시공 남은 주문은 안 비움 · 설정 저장/읽기 · AS 줄 이름판 자료에 AS 기사.
- 실화면: 스테이징에서 가상 주문(`CLAUDE-TEST-`)으로 AS 접수 → 출고 스케줄 AS 줄이 비어 있는지, 이름판에 AS 기사가 뜨는지.
- 올리기: deploy(스테이징)까지. 운영은 따로 말씀하실 때.

## 6. 운영 뒤 고친 것 (2026-11-24)

- **주문 화면 접수가 비운 칸을 다시 채움(운영 PR #911)**: 주문 화면의 AS 접수는 접수 직후 주문을 통째로 저장한다. 화면의 시공자 칸에
  옛 값이 남아 있어 1초 뒤 저장이 다시 써 넣었다(운영 원장: AS_RECEIVED 로 비움 → ORDER_STRUCTURED_SAVED 로 채움). 접수 응답의 값을
  화면 칸에 반영한 뒤 저장하게 고쳤다. 1차 확인이 주문 화면 접수 길을 실화면으로 보지 않아 놓쳤다.
- **옛 AS 줄 비우기 2차**: 접수 순간(2분 안)의 자동 저장이 채운 14건을 더 비웠다(1차 8건과 합쳐 22건). 접수 한참 뒤에 사람이 넣은 2건 ·
  건 기록 없는 옛 AS 1건은 그대로.
- **시공자 없는 AS 줄은 맨 아래 묶음(운영 PR #912)**: 사장님 "배정 안 된 AS 건은 하단 배치". 시공자 없는 시공 줄은 맨 위 그대로,
  시공자 없는 AS 줄만 맨 아래 "AS · 시공자 없음 n건". 묶음 안 순서는 표의 기본 순서(담당자 순).
