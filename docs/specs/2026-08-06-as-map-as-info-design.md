사용자 확정: ① v3 즉시 착수 ② 카드 담당자 행 전체 숨김(실측 지정 버튼 + 주문 영업 담당 표기
모두 — AS 담당 개념 불필요) ③ production 승격은 v3 구현 완료 후 deploy(스테이징) 테스트부터.

2026-08-06 사용자 지시("중대 변경"): AS 탭 지도는 실측 지도와 달리 **AS 정보**를 보여줘야 한다.
현행 AS 지도는 실측 지도 표면(우측 카드·팝업)을 그대로 재사용 — 실측 시간·실측 담당자 등
실측 전용 필드가 노이즈로 남고, 정작 AS 업무 정보(증상·방문일·유무상·분류)가 없다.

## 페르소나 분석 (AS 담당 사무직)

지도를 여는 목적 2가지:
1. **방문 동선 계획**: 어느 지역에 몇 건이 몰렸고, 각 건이 언제 방문 확정/가능인지.
2. **개별 건 방문 협의**: 전화 걸기 전 증상·유무상·가능시간을 한눈에.

우선순위 정보 (카드·팝업 공통):
| 순위 | 정보 | 현행 | 근거 |
|---|---|---|---|
| 1 | AS 분류(방문확정/미결/아직미정/유상미확정) | 없음(필터만) | 동선 계획의 1차 판단 — "확정된 건 위주로 루트, 미정 건은 전화" |
| 2 | 방문 예정일 + D-day | 없음 | 이번 주 갈 곳 식별. 미정이면 "미정"을 경고로 |
| 3 | AS 증상/내용 요약 | 없음 | 전화·방문 준비물 판단 |
| 4 | 유상/무상 | 없음 | 고객 안내 필수 |
| 5 | 가능시간(요일·시간대) | 팝업 1행·필터만 | T4 기구축 — 카드에도 칩 표기 |
| 6 | 연락처·주소 | 있음 | 유지 |
| — | 실측 시간 | 있음(항상 '-') | **제거** — AS와 무관 |
| — | 접수일·좌표 행(팝업) | 있음 | 좌표 제거, 접수일→AS 접수일 |

## 변경 표면 4곳 (as 모드 분기 — measurement 지도 무변경)

### F1. 페이로드 (`foms/services/map_snapshot.py` + `foms/api/cs/as_map.py`)
as 모드 point/order에 AS 필드 보강 (기존 표시 서비스 재사용, 신규 로직 없음):
- `as_bucket` + `as_bucket_label`: 4버킷 키 — `build_as_incomplete_bucket_conditions` 조건별
  id-set 배치 조회(4쿼리, N+1 금지)로 판정. AS 탭 pill과 SSOT 일치.
- `as_visit_date`·`as_visit_dday`: `read_as_visit_date` + `_as_visit_dday` 재사용.
- `as_content_preview`: `as_content_html_to_text` 60자 절단.
- `as_billing`: `as_billing_badge_kind`/`as_billing_state_text` (유상/무상/미확정).
- `as_received_date`: AS 접수일.
- 기존 `as_availability`·`as_availability_label` 유지. measurement 모드 페이로드 무변경.

### F2. 우측 주문 카드 (`map_view.html` updateOrderList as 분기)
- 헤더: `#id` + **버킷 배지**(AS 탭 pill 색 동기: 확정=초록/미결=주황/미정=회색/유상미확정=보라).
- 행 재구성: 고객 · 연락처 · 주소(+수정 버튼 유지) · **AS 내용 요약** · **방문일**(D-day 병기 —
  D-3 이내 빨강 강조, 미정은 경고색 "미정", **지난 건은 빨강 "N일 지남"**) · **가능시간 칩** ·
  유상 배지(해당 시).
- 제거: 실측 시간 행 + **담당자 행 전체**(실측 담당자 지정 버튼·영업 담당 표기 모두 — 사용자 확정).
- CSS: 기존 order-info-row 체계 재사용 + as 전용 배지·칩 클래스 추가(인라인 스타일 금지).

### F3. 팝업 (`map-view-kakao.js` as 분기)
- 단건 PC 테이블: 실측시간·좌표 행 제거 → **분류(버킷)·방문일(D-day)·AS 내용·유무상·AS 접수일** 추가.
  가능시간 행 유지.
- 그룹/클러스터 행: 현행 `measurement_time` 자리 → **방문일 M/D 또는 '미정'** 표기.
- as 분기 판정: point에 `as_bucket` 존재 여부(별도 전역 플래그 불필요, folium 폴백 무영향).

### F4. 마커 pill (최소 변경)
- 현행 유지: 상태색·주말 도트·xN 뱃지. 추가: **방문일 미정 건 pill 테두리 점선**(과밀 회피,
  색 추가 없음). 그 외 pill 변경 없음.
