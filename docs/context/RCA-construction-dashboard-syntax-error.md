# RCA: 시공 대시보드 Uncaught SyntaxError (갑자기 에러가 난 이유)

## 현상
- 시공 대시보드에서 `Uncaught SyntaxError: Invalid or unexpected token` (dashboard:3577)
- 파이프라인 타일(시공대기/시공중/시공완료) 필터링 미동작
- 주문 상세 "로딩 중"에서 진행 없음

## 근본 원인 (GDM 문제 해결 프로토콜 기준)

### 1. 시간 차원 인지 (Temporal Awareness)
**"이전에는 잘 작동하다가 갑자기"** → 코드는 예전부터 **같은 위험**을 안고 있었고, **트리거만 나중에 만남**.

- 알림 목록을 **template literal(백틱)** 안에서 만들면서, `onclick="handleNotificationClick(..., '${n.deep_tab}', ...)"` 처럼 **API/DB에서 오는 값**을 그대로 넣고 있었음.
- 그 값 안에 **백틱(`)** 이나 **`${`** 가 **한 번이라도** 들어오면, template literal이 중간에 끊겨서 **구문 오류** 발생.
- 따라서:
  - **예전에 잘 됐던 이유**: 그때까지 로드된 알림 데이터에 ` 또는 `${` 가 **없었음** (또는 해당 화면/패널을 쓰지 않았음).
  - **갑자기 터진 이유**:  
    - 새로 생긴 알림/딥링크 데이터에 위 문자가 들어갔거나,  
    - 도면/리비전 등으로 `deep_tab`, `deep_event_id`, `deep_target_no` 에 특수 문자열이 들어간 경우.

즉, **코드는 원래 취약했고, “데이터/사용 경로”가 바뀐 시점에 처음으로 에러가 드러난 것**입니다.

### 2. 구조적 의심 (Structural Doubt)
- **같은 패턴**이 시공·생산·메인 대시보드 **여러 곳**에 있음.
- “이 한 군데만 고치면 되지?”가 아니라, **“값을 template literal + onclick 에 넣는 방식 자체”**가 문제.
- 그래서 시공만 고친 뒤에도, **생산/메인 대시보드**에서 같은 데이터가 로드되면 동일 에러가 날 수 있음.

### 3. 조치 요약
| 항목 | 내용 |
|------|------|
| 시공 대시보드 | 알림 HTML을 template literal 제거, `data-*` + 이벤트 위임으로 변경 (완료) |
| 생산 대시보드 | 동일 패턴 제거 및 `data-*` + body 클릭 위임으로 통일 (완료) |
| 메인 ERP 대시보드 | 동일 패턴 제거 및 `data-*` + body 클릭 위임으로 통일 (완료) |
| 교훈 | 서버/API에서 오는 값은 **template literal이나 인라인 이벤트에 직접 넣지 말 것**. `data-*` + 단일 리스너로 처리. |

## 결론
- **왜 이전에는 잘 됐나?**  
  → 그때까지는 **문제를 일으키는 문자를 가진 알림/딥링크 데이터가 없었거나**, 해당 알림 목록을 **시공 대시보드에서 로드하지 않았기 때문**.
- **왜 갑자기 에러가 났나?**  
  → **데이터 또는 사용 경로가 바뀐 시점**에, 원래 있던 **취약한 코드 경로**가 처음으로 실행되면서 SyntaxError가 발생한 것.
