{# 네이버 일괄 발송처리 실행 버튼 + 확인 (NAVER-BULKDISPATCH-01 T4). **두 화면(워크벤치·실측 대시보드)이 이 파셜 하나를 include 한다.** 되돌릴 수 없는 조작의 확인 문구와 요청 코드를 두 벌로 두면 한쪽만 고쳐지는 날이 온다. 배선 규율 2개: * **document 위임 + 싱글톤.** 이 화면들은 셸 프래그먼트로 갈아끼워진다 — `DOMContentLoaded` 에 매달면 스왑 진입에서 죽고, 매번 다시 바인딩하면 클릭이 여러 번 나간다(불가역 조작에서 치명적). * **버튼은 렌더 쪽이 판단한다.** 이 파셜은 버튼이 이미 그려져 있을 때만 동작한다 — v3 풀페이지처럼 스크립트가 통째로 빠지는 셸에서는 버튼 자체가 렌더되지 않는다. 변수: `bulk_dispatch` (문구의 집 수 재진술용). #}
