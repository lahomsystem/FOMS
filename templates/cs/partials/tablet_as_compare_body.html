PC 서브탭/필터/pill/헤더 은닉은 foms-tablet-as-compare.css 코호트 규칙 소유. - 검색: PC 필터폼(.erp-as-desktop-filters)이 코호트에서 완전 은닉되므로, pcbar 안에 순수 GET 폼(`.foms-as-compare-search`, name="q")을 별도 신설한다. tab/sort_dir/bucket/ status/mine 은 hidden input 으로 보존해 검색 후에도 현재 탭/정렬/필터 컨텍스트가 유지된다 (신규 라우트·JS 없음 — erp_as_page.erp_as_dashboard 가 기존 q 체인 그대로 처리). - 카드 방문 블록: 방문일(재조정 date input)+D-day + 시각·시공팀·원 주문 링크(목업 방문 정보). - 카드 foot: 주변 일정 · 사진 관리 · 일정 변경 · AS 완료 · 주문 편집. 일정 변경/AS 완료 배선 = tablet-as-compare.js(as_dashboard_body 에서 defer 로드). AS 완료 = as_completed_date=오늘 저장(field_update SSOT → AS_COMPLETED 전이), 방문일 입력은 기존 as-dashboard.js editable-date-as change 배선이 저장(중복 없음). 데이터: 서버 무변경 재소비(rows). 서비스(as_dashboard_display)가 전/후 사진 (as_before_photos / as_after_photos)·방문 D-day(as_visit_dday)·방문 시각(as_visit_time)을 배치/재소비로 보강한다(N+1 없음). AS 사진엔 전/후 구분 스키마가 없어 created_at vs as_completed_date 로 매핑(근거: 서비스 docstring). 표시/은닉·배타(대조 표시 + 기존 데스크톱 테이블 은닉)는 foms-tablet-as-compare.css 소유 (코호트 @media). 이 파샬은 as_dashboard_body 안에서 erp_mobile_v2_enabled 게이트로만 포함되며, 코호트 밖에선 base 규칙(display:none)으로 완전 무동작. 이미지 탭 → 기존 GlobalImageViewer 재사용: lightbox.js 가 [data-foms-lightbox-gallery] + [data-foms-lightbox-src] 를 자동 마운트(coarse=모바일 뷰어로 위임). 신규 뷰어 없음. 인라인 스타일 금지, 인라인 스크립트 금지(계약 테스트 잠금). ============================================================================ #}
